## 役割を重複させない

各写真は1箇所ずつでのみ使用します。特にHero画像をAboutやFooterで再利用しない
でください。`hero-salon.webp` はサロンの第一印象、`salon-interior.webp` は実際に
施術を受ける空間の空気感、と役割を分けています。どちらも明るいサロン室内で
一見似ているため、差し替え時は**チェアかベッドか**で取り違えないでください。

## 表記のルール

写真に写る人物は実在するスタッフ・お客様ではありません。実在の店舗・スタッフ・
利用者と誤認させるalt、キャプション、氏名、経歴、資格は付けないでください。
セラピストの表示は `Concept Therapist ／ セラピスト・イメージビジュアル` のままに
します。

## 差し替え

実写を入れ替える場合は、同じファイル名・近い比率で上書きすればコンポーネントの
変更は不要です。カードのトリミングだけは `src/lib/site.ts` の `imagePosition`、
Heroとセラピストは各コンポーネントの `object-[…]` で調整します。
