## 確かめて問題なかったこと（reviewer）

- `direction`（`data-direction`）と `heroLayout.alignment`（`data-align`）を読む CSS・TSX の分岐は無い。`tokens()` も palette だけを読む。
- motion は、`@media (prefers-reduced-motion: no-preference)` の中の animation だけで使われる（`both` fill。初期の opacity も、この media の中だけ）。
- shot は通常の review も写真の review も、`screenshotPage` で撮る。どちらの shot も `reducedMotion: "reduce"` なので、motion は screenshot に一切出ない。
- confidence と rationale は描かれない。
- `composition.grid` は 720px 以上で効く。desktop の shot は 1440px なので、visible の扱いは正しい。infoStyle・divider・spacing・typography の各値には、CSS の分岐がある。
- motifs は renderer が `Set` で扱うので、順序を無視する判定は正しい。重複は `checkProfile` が拒否する。
- palette は hex の大小を区別しない比較で、正しい。
- `.ai/tasks.json` の DEV-066 について:
  - allowed_scope（`lib/design-agent/`・`tests/unit/design-agent/`・`.ai/`）は、変更した file と一致する。
  - forbidden_scope（閾値・gate の緩和、DB、flag、Production）にも触れていない。
