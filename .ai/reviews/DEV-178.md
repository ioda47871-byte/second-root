## 研究の道具の強化 (DEV-175 のレビューの Low)

- **(a) 紛らわしい字。** `FACT_NODES_JS` で、U+2010〜2015・U+2212・U+30FC を `-` に、U+FF5E・U+301C を `〜` に寄せる。ページの文字と事実の両側に、1字を1字へ、NFKD の前と後の両方で (NFKD は U+FF5E を `~` に変えるので前にも要る)。持ち主の節の対応は変わらない。守る文字を増やすだけ。
  - 段 D の例: `000‐0000‐<span>0712</span>` (U+2010) と `10:00～<span>16:00</span>` (U+FF5E、事実 10:00〜16:00) の末尾を縁取る → どちらも `PHASE_D_PROTECTED_STROKED`。
  - 段 C の例: U+2010 で書いた事実の末尾の覆い、全角の数字の事実の覆い → どちらも `OVERLAP_PAINT_ABOVE_PROTECTED` と `PIXEL_COVER_PROTECTED`。
- **(b) 変異 (リポジトリの外の worktree の写しで、`dev178/mutate.py`):**

| 変異 | `phase-d.test.ts` の速い組 (17 件) | `phase-c-overlap.test.ts` の合成の例 (65 件) |
|---|---|---|
| M58 事実をブロックごとにしか照らさない | 1 / 17 落ちる | 2 / 65 落ちる |
| M59 NFKD と書式文字の正規化をしない (写像は残す) | 1 / 17 落ちる | 1 / 65 落ちる |
| M60 紛らわしい字を寄せない (新しい変異) | 1 / 17 落ちる | 1 / 65 落ちる |

  変異なしの組は両方とも全部通る (17 / 17、65 / 65)。最後に写しの道具が worktree と同じことを確かめた。段 C に全角の数字の例を足す前の写しの M59 (写像も外した形) は 1 / 64 落ちた。M57 は段 D の道具だけを壊すので、段 C の組では落ちない (0 / 64、参考)。
