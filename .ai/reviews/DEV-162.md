## Fresh Review round 1 (C0 / H1 / M2 / L5) と対応

指摘は Critical 0、High 1、Medium 2、Low 5。すべて同じ PR の追加 commit で直した。有効にするものは何も無い (comp-impl・`.github/workflows`・worker の道・依存は不変)。

- **H-1 isolation のテストが head で落ちる。** 検査器の冒頭のコメントがテストのパスを書いているので、`git grep -E research/decoration-svg` が検査器自身に当たる。→ 検査器自身だけを当たりから除き、ほかは厳しいままにした。あわせて `git grep` の終了の状態が 0 であることと、当たりに検査器自身が含まれることを確かめる (git が失敗して stdout が空でも、素通りしない)。**commit してから**このテストのファイルを走らせ直して通ることを確かめた (git grep は追跡したファイルしか見ない)。
- **M-1 プロトタイプの名前で例外を投げる。** `<constructor/>`・`<g><toString/></g>`・`<__proto__/>`・`<path d="M0 0" __proto__="x"/>` が TypeError になっていた。→ 要素と属性の表の引きを `Object.hasOwn` だけにし、読んだ属性は `Map` に持つ。`checkDecorationSvg` と `checkDecorationAssetFile` は例外を捕まえて符号を返す (`SVG_CHECK_ERROR`・`ASSET_CHECK_ERROR`)。型の違う記録・中身の敵対的なファイルも含めてテストを足した。
- **M-2 ページの側の走査の穴。** 一重引用・引用無しの `src`、`<picture><source srcset>`、`<svg/>`・`<svg/class="x">`、記録した資産を `<img>` 以外で使う (`<a href>`・`<link rel="preload">`・`<input type="image">`)、`style` 属性・`<style>` の `url()`、`<table background>`、`<video poster>`、CSS のエスケープ `url(evil.sv\67)`、`data:image/svg+xml;base64`、拡張子無しの `assets/seam` を通していた。→ `decorationReferenceProblems` を、タグと属性の字句解析器 (二重・一重・引用無しの値、ASCII の大文字小文字を区別しない名前、`/` の区切り、最初の重複が効く) の上に書き直した。許すのは `<img src="記録したパスそのもの">` だけ。ほかの要素・属性で、値 (HTML の文字参照・CSS のエスケープ・`%XX` をほどいた読み) が記録した資産・`.svg`・SVG の media type を指すもの、`data:`、絶対 URL・プロトコル相対は拒む。`<svg` はどの形でも拒む。`style` 属性・`<style>`・CSS の `url(` は指す先を問わず拒む。本番の `htmlSourceProblems` はこの多くをすでに拒んでいるが、研究の検査器はそれに頼らない。挙げられた入力すべてにテストを足した。
- **L-1 `</ g>` を通していた** (閉じタグの名前を trim していた)。→ `</` の直後の空白を拒む。`</g >` は XML どおり通す。テスト付き。
- **L-2 viewBox の幅・高さが 0 や負でも通していた。** → `SVG_VIEWBOX` で拒む。テスト付き。
- **L-3 装飾の印を、タグの生の文字列への正規表現で読んでいた。** → 字句解析した属性から読む。`<img title=' aria-hidden="true" alt=""' src=…>` は落ち、`<img title=">" src=…>` は1つのタグとして正しく読む。テスト付き。
- **L-4 資産の id を検めず、同じファイルの二重の記録も見ていなかった。referrer。** → id は `^[a-z0-9][a-z0-9-]{0,63}$` (`ASSET_ID`)、id とファイルの一意 (`ASSET_ID_DUPLICATE`・`ASSET_FILE_DUPLICATE`)。装飾の `img` に `referrerpolicy="no-referrer"` を必須にした (`SVG_IMG_REFERRER`)。テストの fixture と Chromium のプローブのページも合わせ、文書に書いた。
