- EOF: CPython 3.12.3 の `_ssl.c` は `SSL_read_ex` の戻り値 0 を `PySSL_SetError` が先に `ret == 0` で EOF と扱い、errno を失う（3.13.0a6 の gh-115627 で修正、3.12 へは backport なし）。noble の python3.12 3.12.3 + OpenSSL 3.0.13 で RST・FIN・kernel の timeout がすべて `b''` になることを local で再現。passt 1e6f92b は keep-alive に何も返さない（source）。
- 24b-v2: TCP_INFO の offset を uapi の `linux/tcp.h` と照合、open / FIN / RST / kernel abort / 期限ぎりぎりの abort を local で判定。jail 版と host 版は同一。
- DNS の ip rule 案（198.51.100.53 へは UDP/53 だけ、853 と残りは prohibit）は今の rule より厳しい。
