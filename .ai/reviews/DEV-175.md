## 見つけたこと

- **lib の不具合 (本番の安全の穴) は見つからなかった。** 段 D の形はどれも今の許可一覧が先に拒む。
- **段 C の試作は回転と縁取りの墨を測れない (段 D の試作で補う形):** 段 C の字形の箱は canvas の墨を回さずに置くので、回した語の墨が箱の外に出る (段 C の画素の `PIXEL_INK_OUTSIDE_GLYPHS` で fail closed)。段 C の画素の検査は文字を縁なしで描くので、縁が隣の行の墨に届いても見ない (墨の隙間 2px の2行で確かめた: 段 C は 0、段 D は `INK_ON_TEXT`)。
- **1px の掃引だけが見つけた狭い帯 2 つ:** つぐ手の 欠け を −4° 回すと 686〜691px、ゆげ湯の写真を −2° 回すと 870〜878px と 1290〜1294px でだけ、回した角が画面の右の外へ出る (この容器の書体)。確かめる幅 12 はどれも当たらない。
- **CI に近い書体で縦の字が描き崩れる:** 3店の 明朝 の指定のまま縦にすると、IPAMincho の無い組で `serif` がラテン文字の書体になり、縦の かな漢字 が列の足もとに積み重なって描かれた (画像で見た)。検査は止めた。縦の語の書体の並びに IPAGothic を入れて直した。本番では `web_font` と一緒に決める (オーナーの判断 10)。
- **読む順の規則を直した:** 最初は「縦の要素と隣の要素で、後のものが上かつ右」を一律に落とし、strict のつぐ手にもとからあるジグザグ (写真の札の後の 欠け が右上) で落ちた。縦にしたことで生じた逆転だけを数える (縦の根を横に戻して測り直す) ようにした。もとのジグザグは V9 の範囲として残す (通るべき例と変異 M8)。
- **回転の「画面の外」を直した:** strict のタブレットのはみ出し (レイアウトがもともと外に置く箱) の中の回した箱まで数えていた。回していない箱が中にあるときだけにした (別のテストと変異 M40)。
- C′ の段 D の表現の多く (縦の事実、札ごと回した板、透けた・地に近い縁) は、提案の規則で正しく拒まれる。得は限られ、成功例の水準は主張しない。
