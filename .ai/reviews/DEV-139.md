| # | 指摘 | 対応 |
|---|---|---|
| M1 | 実装の区画の箱を、Phase 2f がデザインの箱を測った規則と違う規則で測っていた (visibility:hidden・display:contents・高さ 0 の根・入れ子の重複)。visibility:hidden で隠した区画の欠落を見逃し、display:contents では誤って欠落と出る | Phase 2f の測り方を写した。同じ id が2つ以上あれば DUPLICATE_SECTION_ID とする。一致のテストに、次の難しい場合を足した: hidden・contents・高さ 0 で中身が絶対配置・切り抜く根・無い区画。区画の一覧が空でないことも確かめる。visibility:hidden の区画が欠落と出ることもテストした |
| L1 | CLI の読み込みで、lstat のあとに readFile していた (間に差し替えられる) | 開いたハンドルで読む (O_NOFOLLOW、上限はハンドルの fstat で確かめる)。パスのどこにもリンクが無いことを実パスで確かめる (`readInside`) |
| L2 | 比較が断ったビューポート (DECODE_FAILED など) を、比べたと数えていた | code が null のものだけを比べたと数える。テストあり (重複の id → not_compared) |
| L3 | 上限の値を schema から写しただけで、一致を確かめていなかった | 一致を確かめるテストを追加 |
| L4 | lane の中の、リンクした `originals/` ディレクトリを辿っていた | `readInside` で実パスを確かめる (file_unreadable)。テストあり |
