- 影響:

  - そのため、別骨格どうしでも「写し」「同じ店の2案が同骨格」と助言される。
  - 初回 High-2（見逃し）の裏返しで、検査の結果を信用できなくする。
- 修正案（どれか、または組み合わせ）:
  - `measuredOnly` のスコアを採用する条件を絞る。例えば、実測された hero か flow が少なくとも一方にあること。または、`single_column_text` 以外の layout が一致していること。
  - 既定の分類（`single_column_text`）だけが一致する場合と、navigation・text_direction・imagery が一致する場合は、`measuredOnly` の一致に数えない（null 扱い）。
  - 宣言側が大きく異なるのに実測だけが一致したときは、max で黙って上書きしない。所見（例: `MEASURED_ONLY_MATCH` / `DECLARED_DIFFERENCE`）として両方の値を出す。
  - 回帰テストとして、上の A / B ページ（宣言も transitions も異なる文字中心の2ページ）で、誤一致が出ないことを固定する。

### H-B（High）Medium-1 の修正が `max-width` コンテナで効かず、典型的な汎用 LP が汎用骨格として検出されない

- 場所: `lib/design-agent/structure/measure.ts:82`（`area(box(main)) >= 0.5 * area(sb)`。`sb` は section 根の box で、padding と左右の余白を含む）
- 仕組み:
  - `section > .inner{max-width:1120px;margin:0 auto;padding:80px 24px}` という標準的な書き方では、ラッパーには降りる。
  - しかし `h2` の下の grid / 2列の面積は、section 全体（1440 幅、上下 padding 込み）の約 45〜48% にとどまり、0.5 に届かない。
- プローブ（すべて desktop 1440）:
  - `h2`＋3枚のカード grid（画像付きでも文字だけでも）は `single_column_text`。
  - `h2`＋リード文＋grid、max-width 960 / padding 96 のものも `single_column_text`。
  - `h2`＋2列（img と文章）は `single_column_text`。
  - これらは、作者の回帰テストの形（コンテナなし、`section{padding:60px 40px}`）でしか通らない。
  - 全面背景画像ヒーロー（中央寄せ見出し＋予約ボタン）・sticky header・コンテナ付きの「おすすめ3枚」「こだわり2列」「アクセス」からなる、教科書どおりの汎用 LP を測った。結果は section_layouts `[full_bleed_media, single_column_text ×3]`、flow `null`。
  - 所見は `ASPECTS_UNKNOWN` だけで、**`GENERIC_SKELETON` が出ない**。hero（centered_headline）だけでは2条件を満たさない。
- 影響: 受け入れ基準の1つ（汎用骨格の検出）が、現実の汎用 LP で外れる。初回 High-1 の「汎用骨格として検出されない」と同じ症状が、別の経路で残っている。
- 修正案:
  - 主の入れ物の面積を section 根とは比べない。降りた親の内容（`big` な子の合計面積など）と比べる。
  - または、section の子孫から「横に重ならず並ぶ兄弟が2つ以上ある最も大きい行」を探す。
  - 回帰テストに、`max-width` コンテナ＋`h2`＋grid / 2列の形と、上記の背景画像ヒーロー LP で `GENERIC_SKELETON` が出ることを加える。

### M-A（Medium）「閉じたオリジン以外には届かない」が成り立たない経路がある

- 場所: `lib/design-agent/structure/measure.ts:117`（「nothing else is ever reached」）、`:129-142`（`context.route` だけに頼っている）
- プローブ: 127.0.0.1 に TCP リスナーを立て、ページから参照させた。

  | 経路 | 結果 |
  |---|---|
  | `<link rel="prerender" href="http://127.0.0.1:P/prerender">` | **HTTP `GET /prerender` が完全に届く**。route を通らず、`blocked` にも数えられない |
  | `<iframe src>` / `<object data>` / `<embed src>` | **TCP 接続が開く**（リクエスト本体は abort される） |
  | `<meta http-equiv="refresh" content="0;url=…">` | **TCP 接続が開く**。さらに `page.evaluate: Execution context was destroyed` で `measurePage` が例外になる |
  | preconnect、dns-prefetch、prefetch、preload、modulepreload、CSS `@import`、`@font-face`、`background` / `cursor` / `mask` / `content: url()`、srcset / picture、SVG `<use>` / `<image>`、video / audio / poster、icon / manifest、`a ping`、speculationrules、`file:` / `ftp:`、プロトコル相対 URL | ローカルのリスナーには届かない（route で abort され、数えられる） |
  | `data:` | ネットワークに出ない（許容範囲） |

- 緩和要因:
  - Phase 2f の prototype は、`lib/design-agent/phase2f/prototype-safety.ts` の静的検査を通る。この検査は iframe / object / embed / meta refresh / `link rel≠stylesheet` を拒否する。
  - 本モジュールはまだどこからも呼ばれていない。
  - ただし `measurePage` 自体はその検査を要求していない。参考例（成功例）など、別の入力元から呼ばれた場合は、任意ホストへの盲目的な GET（SSRF / ビーコン）が出る。
- 修正案:
  - `measurePage` の入口で `prototype-safety` と同じ静的検査を必須にする（または内部で呼ぶ）。
  - 少なくとも `link rel` は stylesheet だけに絞る。`meta http-equiv` と iframe / object / embed は除去または拒否する。
  - ブラウザの起動側で、`--host-resolver-rules="MAP * ~NOTFOUND"` 相当を要件として明記する。
  - コメントの保証文は、実際に守れる範囲に直す。
  - 回帰テストとして、`<link rel=prerender>` がローカルのリスナーに届かないことを固定する。

### L-A（Low）`<form>` 配下の名前による上書きで、測定が例外になる

- 場所: `measure.ts:38-42`（`el.getBoundingClientRect()`、`el.childNodes` を要素から直接呼ぶ）
- シナリオ: `<form><input name="getBoundingClientRect"></form>` と `<input name="childNodes">` で、`page.evaluate` が TypeError になる。黙って欠けるのではなく失敗するので、安全側ではある。また Phase 2f の prototype では form が禁止されている。
- 修正案: `Element.prototype.getBoundingClientRect.call(el)`、`Node.prototype` の `childNodes` getter など、プロトタイプ経由に揃える。

### L-B（Low）ファイル冒頭のコメントが古い

- 場所: `measure.ts:4-5`（「every request aborted (the HTML and CSS are given inline; an image … simply does not load)」）
- 内容: 現在の実装（閉じたオリジンからの配信、画像はプレースホルダー）と食い違う。

## 問題なしと確認した点

- 閉じたオリジンの扱い:
  - 応答するのは `/`・`/index.html`・`*.css`・画像拡張子だけ。
  - 応答はすべて status 200 で、こちらからのリダイレクトはない。
  - 別の `.html`・`.svg`・`.js` は abort され、数えられる（SVG の `<img>` は潰れるが、Phase 2f は PNG 指定なので影響はない）。
- `data-section` がないページ（`<main>` で包む形）は、section が1つに潰れる。ただし Phase 2f のプロンプトが `data-section` を必須にしているので、問題とはしない。
- 背景画像ヒーロー＋カード grid（コンテナなし）は、配色違いの版と類似度 1、`GENERIC_SKELETON` あり。
- スコープは `lib/design-agent/structure/**`、テスト、`.ai/**` だけ。`node:zlib` の追加は PNG の生成に使うだけ。
