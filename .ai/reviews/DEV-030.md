# DEV-030 Sales Design Bridge — review

## Fresh review (2026-10-09, separate context, `git diff origin/develop...HEAD`)

**Result: Critical 0 / High 0.** Medium 3 and Low 7, handled as below.

The reviewer confirmed these as correct:
- **Flag off.** With the flag off, every RPC argument and SELECT is byte-identical to before.
- **Auth.** Bridge auth fails closed (503 / 401). The comparison is constant-time, and a bridge token equal to the ingest token is refused.
- **Strict schemas.** `checkProfile` runs on submit, on the public render and on the admin preview.
- **Claim / submit.** Claims are serialized (advisory lock plus `skip locked`). The job id is the lineage, and `ready` is final.
- **Spool reads.** They use `O_NOFOLLOW`, require a regular file with one link, and enforce a size limit.
- **No photos.** Neither the public demo nor the preview is given photos.
- **No other send path.** Follow-up, DNC, outcome, the Instagram reply flow, history and meetings all act only after the first send.
