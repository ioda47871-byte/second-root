# CP-015 | imairo. — TABLE AS A MAP / TABLE JOURNAL v2

**ステータス:** `OWNER_SELECTED_RESEARCH_SUCCESS`（2026-10-28 JST）。ユーザーが、食卓型の構図を維持したローカルHTML/CSS/JS研究PoC「TABLE JOURNAL v2」を見て、**「成功例とします」**と明示。**14件目の研究成功例として登録**。

**範囲:** 名古屋・今池の `spice & cafe imairo.` を題材にした、Second Root独自の**非公式研究デザイン**。店舗からの制作依頼・許諾・商用素材承認・公式サイト公開ではない。以前の塩釜口住所やAI生成した店舗風景を実店舗の情報として扱わない。

**正本となる採用物:** 「TABLE JOURNAL v2」（紙のノート型の詳細UIを追加したローカルHTML）。評価済みのワイド食卓Hero画像は元データを**ビット単位で維持**した。スマホは卓上を横方向に探索し、紙片ノートを別レイアウトで開く。初稿・途中生成案・標準的な左右交互LP・汎用ドロワー案は採用物ではない。

## 具体的に評価されたデザイン原理

- **食卓そのものがサイトの空間になる。** 南インドのスパイス料理を中央、フランス菓子を右、コーヒーを上方に配した、奥行きのある**一枚のテーブル**を閲覧空間にする。料理/菓子/飲料を3本の写真帯に置き換えない。
- **既に好評だったHeroを保護。** 左側に日本語見出しの余白、暗い木のテーブル、手作り感のある器、温かな光、さりげない英語注釈。新しい画面生成でこの核を失わない。
- **操作をサイト固有の体験へ。** 料理・菓子・コーヒーなどの位置に小さな「＋」を置き、選択時に**傾いた紙片のフィールドノート／ポラロイド風カード**がテーブル上に現れる。一般的な右側サイドドロワーではない。
- **店の特徴から構図を設計。** 南インド料理とフランス菓子・コーヒーの共存を、左右の文化別カラムでなく「一つの食卓を巡る」構造で表現する。
- **スマホ用の別の体験。** 卓上全体を縮小しきらず、横方向に食卓を探索でき、情報ノートはスマホ上で読みやすい位置に出る。ノート切替・閉じる・Escape操作を確認。

## 対照となる失敗例

1. 画像モデルに「食卓」と指示しても、FOOD→PÂTISSERIE→DRINKSの写真帯に戻ってしまった複数の縦長案は採用せず。
2. 「食卓の構造がデザインに反映されていない」とのフィードバックにより、構造ワイヤーを基準に再設計。
3. 好評だったワイド食卓HeroからPC/スマホのフルページ画像を作る際、下層が**汎用LP**になり「ありきたり」と評されたため不採用。
4. Hero周辺にラベル/円弧/矢印/写真帯を足した案は「悪くなった」と評され不採用。**装飾を増やすことは独創性ではない**。
5. Heroを固定した研究PoCの**汎用サイドドロワー**は、ユーザーの「いいと思います、やってみて」を受けて「TABLE JOURNAL v2」の紙片ノートへ刷新。最終案にユーザーが「成功例とします」。

**守るべきこと:** 初稿の魅力が確認された場合、弱点だけ改善。構図の大幅な再生成によって写真・余白・視線誘導の核を失わない。

## 実装・検証状況

- HTML/CSS/JavaScript **ローカル研究PoCあり**。PC・スマホをChromium/Playwright `page.set_content` で検証。320/375/390/430/680/768/1024/1280/1440/1920pxの10画面幅で、ページの意図しない横はみ出し、画像欠落、JS例外は確認されなかった。
- 料理/菓子/コーヒー等のノート表示、ノート切替、閉じる、Escape操作を確認。**本番ブラウザ・実機・Safari/Firefox・Next.jsの検証ではない**。
- **元Heroの文字とナビは画像内に焼き込みのまま**。追加した操作とノートは独立HTMLだが、実用サイトの写真・文字完全分離には未到達。
- ノート用写真はAIコンセプト画像からの研究用切り抜き。**独立した正規の利用許可済み素材ではない**。商用サイトや営業デモへの自動転用を禁止する。
- 実店舗のメニュー・価格・日時・場所・人物・内観の正確性、商用利用許諾、公式サイト化、Vercel公開、クライアント承認はいずれも未検証・未承認。
