# CP-011 | BAR N — GLASS / SILENCE — Structure Recovery v2

**状態:** `OWNER_SELECTED_RESEARCH_SUCCESS_CASE`。2026-10-27 JST、ユーザーがv2ローカルHTML/CSS/JS試作に対して「これを成功例とします」と研究成功例への採用を明示。Second Rootが行う**非公式Webデザイン研究上の成功事例**であり、実店舗の制作依頼・許諾・納品・本番公開の承認ではない。

**対象業種:** 名古屋・伏見のバーを題材としたコンセプト（現場や商品写真、正確な店舗情報の認証は未実施）。

**承認版:** `GLASS / SILENCE HTML PoC v2`（Structure Recovery）。静止画のB案選択のみ、v1 HTML PoC、リデザインポスターとの取り違えに注意。

## 意匠の核と採用理由

1. **巨大なクープグラス:** 黒いHeroと生成りの明るい紙面の境界をまたぎ、脚とグラスの形が画面全体の視線を支配する。
2. **ガラスの屈折光:** 黒、琥珀色、生成りの対比に、ガラスを透過した光の筋を重ねる。単なる装飾よりページの情報接続を担う。
3. **非対称な中盤:** QUIET LIGHTはカウンターの写真が隣接章へ入り、ボトル・グラスを違う奥行きで配置。A MOMENTは左右均等の説明欄から、余白と写真断片を大胆にずらした表現へ移行。
4. **ACCESS:** 3列の均等なグリッドではなく入口の印象を主役にした、不規則な配置と控えめな情報欄。
5. **モバイル専用の再配置:** PCのグラス・光・文章のレイヤーを小画面用に個別調整した。

## 実装証跡・品質の境界

- ローカルの編集可能なHTML/CSS/JS。写真・文字・透明PNGの巨大グラス・光の表現・ナビゲーションは独立レイヤー。
- Chromium / Playwrightで320、375、390、430、768、1024、1280、1440、1920pxの9幅を表示検証した試作ログ。横はみ出し、画像不良、JS例外、無効な内部アンカーはなし。390pxのメニュー開閉とEscで閉じる動作を確認。
- **この承認は美的な研究採用であり**、性能・Safari/Firefox・実機端末・ユーザー調査・アクセシビリティ・Next.jsビルド・Vercel公開を検証した意味ではない。
- 現在の写真の一部はAI生成研究コンセプトからの切り抜き。画質劣化があり、現実の店舗や商品の真正な写真として使えない。写真の使用許諾、商標、所在地、営業時間、予約先も店舗確認・別途権利処理が必要。

## Design Intelligenceとして抽出する原則

**転用してよい方法:** 店舗固有の素材（ここではガラス）を単なる装飾から構図の骨格に変換し、光と視線が複数の章をつなぐように設計する。ヒューマンレビュー後は、良かった要素を具体的に保護し、否定された下層のみ改善する。HTML版の構造が平凡に戻っていないか完成画像とスクリーンショットで比較する。

**別店舗へコピー禁止:** BAR Nという名称、生成画像、特定のグラスの配置・角度、黒×琥珀×生成りのセット、コピー、入口画像、照明のパターン、個別ポスターのレイヤー位置、アクセス情報。
