# PT-02｜B案基準のビジュアル忠実度Web PoC v2

**2026-10-27 / 研究用 / オーナーの完成判定待ち**。先の「本棚が地図になる」カラー3案比較の **B案** をビジュアル基準とする。ユーザーが不採用とした、視覚を犠牲にした背表紙メカニカルUI PoCの復活ではない。

## 実装の方針

1. 温かい本棚写真のHero、木と暖色照明、紙の注釈を保つ。
2. 本棚の背表紙は中盤の写真から切り離したHTML/CSSの本9冊で表現。ユーザー操作で注釈内容を更新するが、サイト全体はメカニカルな実験UIにしない。
3. 店内と本の写真＋紙面の重なり、紙芝居＋明るい紙の解説、畳の余白、案内状をPCとスマホで別々に組み立てる。
4. 写真は過去のAI生成コンセプトの切り出しで、実在店舗の実写や独自制作の商用素材と偽らない。

## ローカル検証

- Chromium/Playwrightで9幅（320,375,390,430,768,1024,1280,1440,1920）をレンダリング。
- 横はみ出し・画像読み込み不良・JavaScript例外はいずれも0。
- PC1440/スマホ390で9冊全ての選択、紙の注釈切替、矢印キー、紙芝居の幕、スマホのメニューをテスト。
- `reference_B_vs_HTML_V2.jpg`、`reference_mobile_vs_HTML_V2.jpg` で元のB案と並べた実画面を保持。

## 視覚上の課題と限界

元のB案は3案比較ボードの約390px幅の一部分であり、写真切り出しを大きく使うとHeroの本棚が粗くなる。色彩豊かな背表紙をHTML/CSSで再構成しているため、参考画像の細かな本の装丁との相違が残る。生成画像内の文字が写真内に残る箇所もある。現時点で **pixel-perfect とも完成品とも主張しない**。
