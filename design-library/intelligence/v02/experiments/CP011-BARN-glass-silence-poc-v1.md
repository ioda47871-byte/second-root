# CP-011候補 | BAR N — GLASS / SILENCE HTML PoC v1

**2026-10-27 / 非公式Second Rootデザイン研究 / オーナー完成判定待ち**

## 評価・採用の履歴
- 初回A案は横長写真帯を繰り返すと判断し第一候補にしなかった。
- B案はユーザーが「２枚目の方がいいね」と方向選択。巨大なグラスが黒いHeroから生成りの紙面へ侵入し、光の屈折が視線誘導になることが核。
- B案の最初のブラッシュアップは「悪くなったな」と不採用。全面再設計ではなく、評価された巨大グラス・白い紙面・光・非対称構造を保護して限定修正。
- 再改良のデザイン画像に対し「良いです」と高評価。ただし**CP-011成功例への正式な登録指示ではない**。
- そのデザインを実際のHTML/CSS/JSへ実装するよう依頼され、**今回のv1 PoCを制作**。このWeb PoC自体へのユーザー評価はまだない。

## デザインを保護した要素
1. 大型の赤琥珀色のクープグラスが暗いHeroから生成りの紙面へ抜ける「境界越え」の構図。
2. グラス脚部から紙の上に広がる光の屈折、琥珀色の照明と暗部の対比。
3. 小さなカクテルの写真、光るボトル棚、静かなカウンター、空白のある一杯の章、控えめな店舗案内という不均等なリズム。
4. 大きなタイポグラフィのコピーを実DOM要素として扱い、写真全体のスクリーンショットを貼る実装を避けた。

## 実装とQA
- 編集可能なHTML/CSS/JS、レスポンシブCSS。オフラインでも見られる単独 `preview_offline.html` も用意。
- Chromium / Playwrightで幅320、375、390、430、768、1024、1280、1440、1920pxの**9幅**を表示検証。
- 横方向のページ全体はみ出し0、画像読み込み不良0、JSエラー0、無効なページ内リンク0。
- モバイルメニューの開閉・Esc閉じを390pxで動作確認。
- スクリーンショット `1440_full.png`・`390_full.png`・構図比較を作成。
- **美的品質のオーナー承認や商用完成を示す検証ではない**。ブラウザ描画での構図再現と主要操作のみ。

## 素材の重要な限界
- 写真素材を独立した高解像度で生成しようとしたが、画像生成が再びWebデザイン全体の画像になり、要求どおりの独立写真とはならなかった。
- 完成サイトの写真は**承認されたAI生成研究デザインからの切り出し・切り抜き**が中心。透明なグラスをピクセルマスクで切り出し別レイヤー化したが、新たな高解像度写真の撮影・生成と同義ではない。
- 研究写真の店内・入口は実際のBAR Nの現場写真とは限らず、ロゴや看板・所在地・営業時間などの真正性は未確認。公式公開・営業素材利用には**店舗の許諾、情報の照合、写真権利処理、独立高解像度写真による置換**が必要。
- アクセス表示は「名古屋・伏見」の研究表現のみ。営業時間・正確な住所・予約・地図リンクは未検証のため掲載しない。
- 本番Next.js、Vercel、Supabase、営業AI、自動デザイン生成器の変更なし。**成功事例manifestには登録せず**、CP-011の採用待ち。
