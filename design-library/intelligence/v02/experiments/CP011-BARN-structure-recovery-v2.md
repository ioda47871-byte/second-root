# CP-011候補｜BAR N GLASS / SILENCE — Structure Recovery v2

**2026-10-27 / Second Root非公式研究 / オーナーのv2外観評価待ち**

ユーザーはv1 Web PoCに対して「ちょっとありきたりかな」と評価。元のB案の巨大クープグラス、黒→生成りの境界越え、屈折光、静かな高級感を**保護したまま**、下層の横長写真帯の反復を減らすHTML/CSS改修を実行した。

## v1との差分（写真・文字は独立DOMレイヤー）

- **Hero / THE VESSELS:** 採用されたB案を基準に**変更しない**。大きな赤いグラスを透明PNGの別レイヤーで重ねたまま残す。
- **02 QUIET LIGHT:** カウンター写真の大きな斜めの面と、上部に差し込まれたボトルの断片、下方のグラス写真を異なる深さで重ねる。章の切り替わりも水平線ではなく斜めの切り込み。
- **03 A MOMENT:** コピーを独立した紙の余白に残しながら、巨大な写真面・小さな切り抜き写真二枚・光の反射層をずらし、従来の均等な2カラムを崩す。
- **04 ACCESS:** 均等な3カラムを廃止し、入口を主役にした広い写真面へ細い文字・抽象的な案内図を重ねる。案内図は地図上の正式位置を示さない。
- **390pxモバイル:** PCレイアウトの比率縮小ではなく、節ごとの文字・写真の密度とグラスの重なりを個別に調整。
