## 方向からのずれ・制約 (DIRECTION_FIRST)

どれも事実と安全の規則には触れない。評価のあとに run の記録へも写す。

- 方向は分類 (F2 `bakery`) を中立なラベル「パン工房」で示すとした。ページはそれに従い、`bakery` の文字列は出していない。**ブリーフの must_show の F2 は、値そのままではなくラベルで満たしている。** LAYOUT_FIRST は `bakery` をそのまま出し、VISUAL_FIRST の prompt は値そのままを求めるので、方式のあいだで F2 の出し方が違う (条件の違いとして記録する)。
- 方向は「キーボードの焦点を見えるようにする」としたが、実装レーンの CSS 許可一覧は状態の擬似クラス (`:focus`) を許さない。ブラウザの既定の焦点の表示のままにした。
- 方向の値と実装の小さな違い。方向の文は「ほぼ」「程度」の幅を持つが、記録しておく。
  - 色: 方向の4色のほかに、暗い面の上の補助の文字と罫線に、中間の色を2つ使った。
  - スマホ: 2つのリンクは、暗い帯の「すぐ下」ではなく帯の中に置いた (文書の順を変えずに置けるのは帯の中だけ。CSS 許可一覧は `order` を許さない)。
  - スマホ: F10 の前の罫線は短くせず、幅いっぱいにした。
  - F10 は開きの区画に置き、パンの区画へは罫線で続けた (F10 の文自体はパンの区画に繰り返していない)。
