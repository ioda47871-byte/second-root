# MOCK — DIRECTION_FIRST の方向の文書 (模擬)

**MOCK。** これは Codex の方向の呼び出しの代わりに手で書いた模擬の文書である。Codex の出力ではない。方向の呼び出しの入口と prompt はまだ無い (DEV-143)。方式の優劣の証拠にしない。

Design DNA の8観点 (`DNA_PARTS`) を、この順で1つずつ書く。ページに出す文は、事実の値と40字以内の中立なラベルだけとする (研究の §4)。

## hero

紙袋に押した丸いスタンプのような店名を、最初の画面の中心に置く。スタンプの外側に、朝の石窯の一行を添える。

## typography

店名とパンの名前は明朝。案内の見出しは小さく字間の広いゴシック。太さは2種類まで。

## palette

クラフト紙の茶 (地)・墨 (文字)・小麦の黄 (差し色) の3色。暗い帯は作らない。

## product_visual

素材は1枚 (A1)。紙袋の窓のように、角の丸い四角で切り抜いて見せる。パンの名前は、レシートの品目のように並べる。

## section_rhythm

レシートのように、細い点線の罫で区切った縦の流れ。帯の色は変えない。区画の幅は狭く、中央に寄せる。

## navigation

ナビゲーションは置かない。1枚の紙を上から読む。

## mobile

スタンプ → 窓 → 品目 → 案内 の順に1列。スタンプは画面の幅の 7 割まで縮める。

## implementation

HTML と CSS だけ。JS・外部の読み込み・Web フォントは使わない (B方式の制約)。
