## 再現したもの

- **器の割れ目を通る金の線が、結び目まで1本で続く。**
  - PC: Hero の SVG の出口 (x=70%) から破片の3行を通り、断面、一か月 (目盛りの中央)、相談 (写真と文字の間) を経て、来店の結び目 (x=74%) で終わる。
  - SP: 中央を、Hero から結び目まで通る。b にあった「器では中央、下では左」の段違いは無い。
- **縁取りの巨大な文字が区画の境をまたぐ。** 継ぐ は Hero と破片の境、待つ は断面と一か月の境をまたぐ。
- 傾いた破片の板と影。割れ・欠け・ひびの形 (clip-path) も再現した。
- 縦書き (店名・区画の見出し・一か月の事実と文) と、地の色の律動 (生成り → 灰 → 漆の黒 → 生成り → 漆の赤 → 生成り)。
- strict の実装 b の誤りは、どれも出ていない。
  - 語の途中の改行が無い (keep-all と <br>)。
  - 均質な格子にならない。
  - 板の比が崩れない。

## 残る問題

- 写真は仮の板である。カンプも同じで、実際の写真は別の承認が要る。
- 器は線画のままである。これはカンプの問題 (`COMP_DRAWN_FLAT`) で、忠実さのため直していない。
- PC の来店の右半分が空く。これもカンプと同じ (`COMP_EMPTY_AREA`)。
- PC のページの高さは 5940 で、カンプは 6020 である。破片の区画は中身で決まるので、約 80px 違う。
- 768 と 1024 の縦積みは、右の 3 割が空く。線を Hero の出口 (70%) に合わせた選択の代償である。
- 縦積みでは、相談の机がカンプのように手元の写真と重ならない。
- **本番の規則 (comp-impl) では、この実装は通らない。**
  - position、transform、clip-path、SVG、writing-mode、text-stroke、グラデーション、負の margin、`order` を使っている。
  - 本番へ持ち込むには、要る性質を最小に挙げ、別 PR でオーナーの承認を得る必要がある。
