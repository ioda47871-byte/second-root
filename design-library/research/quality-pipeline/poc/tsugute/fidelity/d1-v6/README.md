## 変えたこと

- **Hero の器の下の影 (L1)。** 床の楕円 (`.bowl-floor`) は器より広く (rx 300、ry 26)、601〜1199 で tagline の こ ろ に 、 の後ろに入っていた (768 で x 295〜342・y 399)。
  高台の下だけの細い影 (rx 104、ry 14) にした。どの幅でも tagline と lead から離れる。
- **SP の Hero (名前と器)。** SP の つぐ手 (h1、店の名前) は縦書きで右に立ち、ぐ・手 が器の暗い内側に掛かって、地とのコントラストが 1.0 の画素があった。
  器は前の版の大きさのまま、線もまっすぐ割れ目へ下りるままにして、つぐ手 を器の上の紙の地に横に置いた (22vw)。名前は字の箱と同じ高さの紙の地に乗り、線はその地の下を通る。
  (途中の版で器を 0.6 倍にしたが、器の重さが無くなり線が揺れて見えたので戻した。) **縦書きから横書きへの変更は、オーナーの確認が要る。**
- **板の影と言葉 (SP)。** 板 (と名札) の影が 割れ・欠け・ひび の上に届いていた。言葉を板より前に重ね (z-index 3)、名札・漢字・文の地の帯を字の箱より広くした
  (漢字は上下に .12em、どの帯も右に 6px)。名札と言葉の間は 24px のまま。線は帯の下を通る (6px は 線の断面 の右端に 364〜369 で線が並んだため)。
- **Hero のコピーの幅 (601〜1199)。** 44% では lead の最後の 。 が 731〜744 で Hero の線に届いた。38% にした。
- **乾く時間 (601〜1199)。** 乾く器の板が格子の下に全幅で置かれ、左半分が句の横で大きく空いていた (768 で板の上に約 400px)。
  板を句の左の列の上へ上げた (左から 板・句・目盛りと線・事実)。区画は 768 で 1185px → 807px になった。
- **相談 (601〜1199)。** 手元の板の影が 相談 に届いていたので、コピーの上を 76px にした。
- **巨大な語。** SP の 継ぐ を 22vw・-26vw にし、壊れ方をなぞる。 と Hero の最後の行から離した (8〜13px まで近づいた)。PC の 待つ を 40px 下げ、線の断面 から離した (広い字の高さで 5px まで近づいた)。
