## 変えたこと

- **Hero の器の下の影 (L1)。** 床の楕円 (`.bowl-floor`) は器より広く (rx 300、ry 26)、601〜1199 で tagline の こ ろ に 、 の後ろに入っていた (768 で x 295〜342・y 399)。
  高台の下だけの細い影 (rx 104、ry 14) にした。どの幅でも tagline と lead から離れる。
- **SP の Hero (名前と器)。** 掃引すると、SP の つぐ手 (h1、店の名前) が器の暗い内側に掛かり、地とのコントラストが 1.0 の画素があった (前の版の README が「飾りの構図」として残していた所)。
  器を 0.6 倍で左に描き、線は上から器の割れ目へ曲がって入り、高台の下で中央へ戻るようにした。名前は 26vw で右の列に立ち、器に掛からない。
- **板の影と言葉 (SP)。** 板 (と名札) の影が 割れ・欠け・ひび の上に届いていた。言葉の上を 56px 空け、名札・漢字の地の帯を字より広くした (線は帯の下を通る)。
- **相談 (601〜1199)。** 手元の板の影が 相談 に届いていたので、コピーの上を 76px にした。
- **巨大な語。** SP の 継ぐ を 22vw・-26vw にし、壊れ方をなぞる。 と Hero の最後の行から離した (8〜13px まで近づいた)。PC の 待つ を 40px 下げ、線の断面 から離した (広い字の高さで 5px まで近づいた)。

## 確かめたこと (リポジトリの外の使い捨ての道具)

ゆげ湯 d1-v5 の README と同じ道具・同じ3つの書体の設定 (`ipa`・`alt`・`wide`) で、320〜1920 の全部の幅 (1px ごと、1601 幅) を数えた。

320〜1920 の 1px の掃引 (3つの書体) は**終わる前にこの記録を書いた**。終わった確かめは、321 幅 (5px ごと) の字の箱と板の数 (3つの書体で重なり 0、巨大な語といちばん近い文字 30〜35px) と、320・340・360・375・390・480・600・601・768・1199・1200・1440・1920 の画素の数 (0) だけである。

前の版 (d1-v5) は同じ道具で、601〜1199 の tagline に床の影の画素 (768 で 775)、601〜1199 の 相談 に板の影、SP の つぐ手 に器 (コントラスト 1.0)、SP の 割れ・欠け・ひび に影が出た。(前の版の全幅の数は取っていない。上は幅を選んだ測りである。)

**見たもの:** PC 1440 の全体 (0.28 倍、2列)、SP 390 の全体 (0.5 倍、4列) のカンプの描画。C を 1440 (0.25 倍、前の版と並べて)、768 の Hero (等倍、前の版と並べて)、390 の上半分 (0.5 倍、前の版と並べて) で見た。
