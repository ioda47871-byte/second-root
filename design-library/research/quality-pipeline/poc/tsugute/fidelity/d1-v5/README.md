## 変えたこと

- **乾く時間の区画 (PC 1200 以上)。** 待 を断面の区画へ上げたあと、つ の下の左半分が空き、右に器の板と縦の文が寄っていた。
  乾く器の板を つ の下の左へ移して -2.4deg に傾け、句 (急がない。線が固まるのを、待つ。) を事実の右へ移した。
  縦書きは右から 句・事実・目盛り・器 の順に読める (前は事実が句の右にあり、読む順が逆だった)。文は変えていない。
- **線の入口と出口 (PC 1200 以上)。** 線は区画ごとの SVG に区画の箱の % で描く。破片の区画の高さが px の余白と言葉の列で決まり、
  板だけが幅で縮んだので、1200〜1439 で入口と出口がずれた。区画の高さと余白を 1440 の値の vw にし (割れ 46.74vw、欠け 35.28vw、ひび 31.04vw)、
  板を行の頭に置いた。ひびは名札が板の上にあるので、写真の頭が 7.3vw になるよう `calc(3.13vw - 33px)` で下げ、言葉の列の下の 140px の詰め物を外した。
- **割れの出口 (1440 でもずれていた)。** 割れの継ぎ目は切り抜きの縁で見えて終わるが、ページの線はその約 20px 左から出ていた。
  線の下側を、継ぎ目が見えて終わる点 (区画の 70.49%・77.56%) から曲げ始めるようにした (板の下に隠れる所で x を寄せる)。

## 確かめたこと (リポジトリの外の道具、DEV-167 の道具を写して使った)

18の幅 (320・340・360・375・390・420・480・600・601・700・768・900・1024・1100・1199・1200・1300・1440) で次を数えた。

- 線・飾り・板 (影を切って) を隠した描画との画素の差を、1文字ずつの箱 (字送りの空きを除く) で数えた (飾りがふつうの文字の上に描いたか)。
- 巨大な語どうしの箱の重なりと、ページの端のはみ出し。ふつうの文字が画面の端を出るか。
- 文字の画素とその下の地のコントラスト (4.5:1、大きな字は 3:1)。
- 変えた所の幅で、本文と事実の文の行の切れ目を1文字ずつ書き出し、句の途中で折れていないかを読んだ。

そのうえで、描いた画像を Read で見た (下の「見たもの」)。ほかの幅は確かめていない。

結果: 線・飾り・板がふつうの文字に掛かる字は 0。ふつうの文字で端を出るものは 0。4.5:1 を下回る小さな文字は 0。
残る当たりは前の版と同じ飾りどうしの重なり (縁取りの つぐ が板に掛かる、600・1200・1300・1440) と、SP の Hero の大きな つぐ手 が器の暗い内側に掛かる画素 (飾りの構図) だけである。
乾く時間の区画の縦の文は折れない (`white-space: nowrap`・`max-content` のまま)。

**見たもの:** PC 1440 の全体 (0.28 倍)、乾く時間の区画を 1440・1300・1200 (0.35〜0.4 倍)、割れの出口を 1440・1200 の等倍。SP は描画が前の版と同じバイト。
