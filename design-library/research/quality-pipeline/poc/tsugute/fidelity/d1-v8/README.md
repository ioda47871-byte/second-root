## 変えたこと (CSS だけ)

**PC 1200 以上: 乾く器の板を右の列へ。**

- 前は、つ の下の左に乾く器の板、線の右に縦の事実、その右に句 急がない。… が立っていた。続く相談の区画でも、手元の板が左に来る。
- 板を事実の右の列へ移し、右へ 2.4° 傾けた (前は左へ −2.4°)。区画の下の端より上で止まる。
- 句を目盛りの左へ移した (1199 以下と同じ側)。縦の文は右から左へ「板、事実、ひと月の目盛り、句」と読む。左上の つ は一つで残り、その下は紙の地の余白になる。
- 写真の順は 乾く器 (右) → 手元 (左) → 机 (中ほどの右) で、左右が交互になった。区画の高さは 70px 伸びた (PC 1440 の高さ 6110 → 6180)。

**1199 以下: 相談の見出しを手元の板の前へ。**

- 前は、乾く器の板 (乾く時間の最後) のすぐ後に手元の板 (相談の最初) が来て、板が2つ続いた。
- 相談の区画を縦の flex にし、文の箱を `display: contents` にして、表示の順を ラベル 相談 → 見出し → 手元の板 → 事実の文2つ → 机の板 にした。HTML の順と文は変えていない。
- 板と板の間には、いつも文が入る。手元の板は前と同じ幅 (最初の試しで縦の flex の中で縮んだのを、`align-self: stretch` で直した)。

**SP 600 以下: 器を結び目の真下へ。**

- 前の版は、器を区画の下 (下から 72px) に置き、線は結び目 (上から 104px) で止めていた。線を器まで続けると、中央に並ぶ事実の行 (所在地・道順・時間・定休・電話) の下を 300px 以上通るので、続けなかった。
- 器を結び目の真下へ上げた。器の箱の上の端を結び目の中心 (上から 104px) に置き、割れ目の上の端 (器の 420 単位の 214、幅 200px で 101.9px) を線の x に揃えた。線は結び目を通って器の縁の上で割れ目に入り、器の底まで金の割れ目が続く。
- 見出し 線の終わりは、ここ。・事実の行・免責の文は器の下に来る。**線は事実の行の下を通らない** (線は器の割れ目で終わる)。
- 区画の下の余白は 280px → 56px。器が上へ来たぶん、事実の行は約 140px 下がり、ページは 56px 短くなった (390 の高さ 6494 → 6438)。
