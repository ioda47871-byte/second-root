## 変えたこと (601〜1199 だけ。PC 1440 と SP 390 の描画は前の版と同じバイト)

**線と器。** 601〜1199 では、線は x 70% を縦に下り、来店の区画の結び目 (上から 132px) で止まっていた。直った器 (割れ目に金の線を描いた器) は、区画の下から 92px の所に、線から 600px 以上離れて立っていた。
PC 1200 以上では、線は結び目を通って器の割れ目へ入る。だから 601〜1199 だけが、線の物語 (割れ目をたどって最後に器へ) の最後で切れていた。

- 結び目の中心から器の割れ目の上の端まで、同じ金の 3px の線を続けた (`.seam-sp-tail`、aria-hidden の空の `div`)。
- 器の割れ目の上の端は、器の箱の 107/210 の位置にある。器を 2px 左へ寄せて、その端を線の x に揃えた。線は割れ目の上の端に 12px 入って終わり、器の縁より上で細い割れ目に移る (601・768・1199 を 4 倍で見た)。
- 免責の文 (比較研究用の…) の右に、線から 24px の余白を足した。601 では文が線の下まで届くので、2行に折れる (SP の高さは変わらず、601 は 24px 伸びる)。
- 600px 以下は変えていない。SP は線が中央を通り、情報の文が中央をまたぐ。続けると、線が事実の行の下を 300px 以上通ることになるので、今回は触れなかった。

## 確かめたこと (リポジトリの外の使い捨ての道具)

**掃引。** 601〜1199 の全部の幅 (1px ごと、599 幅) を、3つの書体の設定で数えた。設定と数え方は ゆげ湯 d1-v5 の README と同じである。

| 設定 | 幅 | 巨大な語の字の箱の重なり | 板・要素が文字の上 | 画素の差 (飾り→文字) | はみ出し / 切れ | 4.5:1 未満 | 巨大な語といちばん近い文字 |
|---|---|---|---|---|---|---|---|
| ipa | 599 (601〜1199) | 0 | 0 | 0 | 0 / 0 | 0 | 83px |
| alt | 599 (601〜1199) | 0 | 0 | 0 | 0 / 0 | 0 | 64px |
| wide | 599 (601〜1199) | 0 | 0 | 初回 2 (763、1188) → 1幅ずつ描き直すと 0 (負荷の下の描画の揺れ) | 0 / 0 | 0 | 34px |


**位置の数 (`fidelity-measure`)。** 線の motif の縦の被覆が、1024 で 0.843 → 0.965、768 で 0.823 → 0.960 になった。
いちばん長い切れ目は 1043px → 230px で、残る 230px は器の下の余白である。

**見たもの:**

- 1440・768・390 の前と後の全体
- 768 の来店の区画 (0.75 倍)
- 601・768・1199 の線と器のつなぎ目 (4 倍)
