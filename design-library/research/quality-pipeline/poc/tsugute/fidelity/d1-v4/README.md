# つぐ手 d1 v4 — experimental_fidelity (研究専用、本番用ではない) (DEV-167)

2026-11-04。オーナーの指示「つぐ手・輪・ゆげ湯のカンプそのもののデザイン品質も引き続き改善する」と、
リードが C (d1-v3) の PC 1440・SP 390 の描画を見て挙げた直しによる。

- 前の版は `../d1-v3` で、そのまま残す (`photo-slots.json` はその版に固定されている)。
- これは**カンプ `comps/d1-seam-across-v3` の実装**である。カンプは前の C (d1-v3) の描き方を取り込んで作り直したので、
  この C はカンプと**同じ HTML・copy.json** を使い、CSS は先頭の注記だけが違う。描画はカンプと同じバイトになった (下の表)。
  そのため `fidelity-report.json` の C の数は、カンプとの差ではなく、位置の指標としてだけ読む。
- B方式の隔離された描画レーン (`checkPrototype`、JS 無効、通信遮断) を通る。本番の実装レーンの許可一覧は変えていない。
- **成功例の水準とは言わない。** 採るかはオーナーが画像を見て決める。

## 変えたこと

- **T1 壊れ方の板。** 割れ・欠け・ひびの3枚の板に、壊れ方と金の継ぎを SVG で描いた。板は写真の仮の板のままで、
  SVG は飾り (`aria-hidden`、`data-pa-role="decoration"`) である。
  - 割れ: 板を縦に横切る1本の割れを、金のジグザグの継ぎ目で結ぶ。片側を少し沈ませ、割れの影を付けた。
  - 欠け: 縁の欠けを金で埋め、金の縁取りが欠けの形をなぞる。PC は右の縁、SP は上の縁。
  - ひび: 細い金のひびが枝分かれする。主のひびは少し太い。
  - ページの金の線が、各板の縁から入って壊れ方の形になり、縁から出る。PC は区画ごとの線の経路を、1440 で測った板の入口と出口に合わせた
    (割れは上下、欠けは欠けの両角、ひびは上の縁と左の縁)。SP は中央の線の位置に合わせた別の描き方を出す。
- **T2 小さな金の文字。** 明るい地の区画ラベル・修理名・情報のラベルを濃い金 `#765417` (生成りの地で 5:1 以上) にし、
  PC 13〜15px・SP 13〜14px に上げた。写真の名札は 13px、濃い灰 `#5c5447`。暗い地のラベルは明るい金のまま。
- **T3 線の断面。** 金の線が積み層 (金・漆・割れた器) を縦に貫く。線は層の上に描き、文字の右を通る。
  器の層には漆で埋まった割れ目が開き、金の層の上に金の盛り上がりがある。層には陰と粒を足した。
  見出しの下の空いた左には、縁取りの 待 が立つ (つ は次の区画へ)。SP では 待つ を左の縦の列に移し、中央の線が文字を切らない。
  タブレット (601〜1199px) は線が断面の横を通るので、割れ目と盛り上がりを出さない。
- 前の版から持ち越した欠陥: ひびの区画の線の SVG の高さが幅と同じ (1440px) になり、線が漆の区画を余分に下っていた。区画の高さに合わせた。

## 測ったこと (`scripts/design-artifact/fidelity-measure.ts`)

1440・390・1024・768 のどれでも、説明の行が覆われた数・線に横切られた数・巨大な語の途中の改行・横のはみ出しは 0 だった。
核の覆いは前の版と同じ水準 (PC 0.984、SP 0.951。カンプは古い `d1-seam-across-v2` のままの仕様で測った)。
この計測は `elementFromPoint` を使うので、`pointer-events: none` の線が文字を横切っても数えない。線と文字は描いた画像を見て確かめた。

## まだ残ること

- **写真は仮の板のまま。** 板の上の壊れ方は描いた飾りで、実写真ではない。
- 器と破片は描いた絵で、焼き物の質感は写真に及ばない。
- 待 を断面の区画へ上げたので、乾く時間の区画の左下が少し空いた。
- PC の線の入口と出口は 1440 の板の位置に合わせた。1200〜1439px では数 px ずれる。
- 区画のラベルと 待つ は創作の文で、オーナーの確認が要る。
