# つぐ手 d1 v3 — experimental_fidelity (研究専用、本番用ではない)

2026-11-03、Issue #193 コメント `6598906140` と、オーナーの指示「C 方式でも残るデザイン上の問題を修正する」による。

- 前の版は `../d1-v2` で、そのまま残す。
- これは B 方式の隔離された描画レーン (`checkPrototype`、JS 無効、通信遮断) の中の実装である。本番の実装レーンの CSS 許可一覧では通らない (許可一覧は変えていない)。
- **成功例の水準とは言わない。** 採るかはオーナーが画像を見て決める。

## 作る前に見たもの

Claude が自分で開いて見たものは次のとおり。

- 成功例 CP-003 (登録済みの WebP、PC を2つに切って見た)
- カンプ A
- この前の C (d1-v2) の PC・SP

CP-003 と比べて C が足りなかったものは次のとおり。

1. **主役の物の質感。** CP-003 の豆は写真で、重さと光がある。C の器は平らな線画で、模式図に見えた。
2. **写真の板。** 灰色の斜線の板で、置いた写真のように読めなかった。
3. **小さな編集の見出し。** CP-003 には、区画ごとに小さなラベルと罫がある。C には無かった。
4. **最後の区画。** PC の来店の右半分が空いていた。
5. **タブレット (1024・768)。** 線の右の 30% が空いていた。

## 変えたこと (2巡)

### 1巡目

- **器。** SVG のグラデーションだけで、釉薬の器にした。ラスター画像や生成した画像は使っていない。
  - 外側は、上の生成りから下の茶へ。左右に陰を付けた。
  - 内側は、漆の黒赤の見込みにした。
  - 縁に光、腹に一本の照り、高台、床の影を足した。
  - 割れ目の金の線はそのまま。
- **写真の板。** 陶の面を暗く写したような、色の調子と細かな粒だけの仮の板にした。何かの写真に見せかけたものではない。
  - 四角い板 (手元、机、乾く器) は、白い余白のある紙焼きにした。
  - 名札は残した。
- **小さな見出し。** 金の罫と字間を広げた小さな語を足した (壊れ方・漆と金・ひと月・相談・来店)。
  - 文の記録に、創作の文 (`owner_review_needed: true`) として足した。
- **最後。** 線の結び目から、継いだ器の金の線へ続くようにした。来店の見出しは左寄せにした。PC の右半分が埋まり、線がここで器に戻って終わる。

### 2巡目 (1巡目が起こしたことを含む)

- 右の破片の見込みと縁の線が、器の外へはみ出した。見込みを破片の形に合わせ、全体の縁の線を外した。
- 継いだ器が来店の見出しに重なった。見出しを左へ移した。
- SP では、継いだ器が電話番号の地に隠れた。SP の下の余白を広げ、器を最後に置いた。
- タブレットでは、破片の大きな語と説明を線の右へ移した。右の 30% を使うようになった。
- 小さな見出し (壊れ方・ひと月) が、SP とタブレットで隣の要素に覆われた。流れの中へ移した。

## まだ残ること

- **写真は仮の板のまま。** 色の調子は付いたが、成功例の写真の力には遠く及ばない。実際の写真か生成の画像が要り、それは別の承認が要る。
- **器は描いた絵である。** 釉薬の質感は出たが、写真の器ではない。割れた破片の厚みも描いていない。
- **破片の区画は、PC でまだ余白が多い。** CP-003 ほどの密度は無い。
- **小さな見出しの語は創作の文である。** オーナーの確認が要る。
- **タブレットの相談と線の断面の区画は、まだ線の左だけを使う。**
