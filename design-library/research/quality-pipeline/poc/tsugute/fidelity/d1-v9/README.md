## 変えたこと

**文はどの幅も横書き (縦書き `writing-mode` を使わない)。**

- 事実 漆が乾くまで、修理には一か月ほどかかります: PC は線の右に横書き2行 (28〜40px)、その下に乾く器の板。601〜1199 は線の左の広い列に横書き。600 以下は線の左に横書き4行 (線は事実の下を通らない)。
- 句 急がない。線が固まるのを、待つ。: PC は つ の下に右寄せの横書き2行、601〜1199 は事実の下、600 以下は線の右。
- 壊れ方の見出し (PC): 縦の1列から横書き2行へ。
- 縁取りの 待つ・継ぐ と名前 つぐ手: `<br>` で 1行1字の柱 (横書きの送り、行の高さ = 前の縦の字の送り)。並びと字の大きさは前と同じに見えるが、字は横の送りで置かれるので、どの書体でも重ならない。

**写真の並び (320〜1199)。**
