# ゆげ湯 d1「温度を下る」: カンプと Web 実装の見比べ (Issue #193、3業種の検証の2つ目)

2026-11-03。カンプ `comps/d1-heat-descent` を、実装レーンの規則 (`lib/design-agent/comp-impl/page-css.ts` と HTML の許可一覧) の中で Web ページにした。PC 1440 と SP 390 を描き、Claude がカンプと並べて自分で見た。**品質の判定ではない。** 採るかはオーナーが決める。

- 2つの実装はどちらも、`htmlSourceProblems` と `cssProblems` で問題 0 件だった。
- 写真は1色の仮の板 (64×64 の単色の PNG) である。
- 描いた画像はリポジトリの外に置き、SHA だけを残す。条件は JS 無効・外への通信拒否・deviceScaleFactor 1・ページ全体。

## a: 見て分かった品質の低下

- **実装の誤りが2つあった。**
  - 単色の 64×64 の画像を `width: 100%` で置いた。そのため、庭の水風呂の板が 1440×1440 の正方形になり、ページの4分の1を占めた。
  - 湯船の板も正方形になった。
- 左端の温度計の帯が無くなった。
- 店名の縦書き、境をまたぐ縁取りの巨大な文字、傾いた板と影が無くなった。
- 火の目盛りの帯が1色になった。
- タイルの目地と山の絵が無くなった。

## b: 直した版 (規則はそのまま)

- **板の縦横比を戻した。** すべての板に `aspect-ratio` を付けた。
- **温度計の帯を戻した。** 各区画の内側の塊の左の罫を、区画ごとの温度の色にした。帯は朱から紺まで途切れずに下る (色は区画ごとの段になる)。
- **火の帯を4段の色にした。** 1本の色から、炭・朱・橙・薄い黄の段にした。
- **湯船の2枚の板を横に並べ、高さをずらした。** 1列の縦積みをやめた。
- **山の絵と庭に、役割の色の板を使った。** 山の絵は青、庭は水色にした。
- ページの高さがカンプに近づいた。PC は 6646 から 4589、カンプは 5020 である。

## まだ残る低下と、その出所

| 低下 | 出所 |
|---|---|
| 店名と巨大な文字が横書き。熱い が 256px を超えない | 規則 (横書きだけ、文字は最大 256px) |
| 巨大な文字が塗りで、縁取りにならない。区画の境をまたがない | 規則 (`-webkit-text-stroke`・負の margin・position が使えない) |
| 板が傾かない。影も重なりも無い | 規則 (transform・外側の影・position が使えない) |
| 湯気のにじみ、温度計と火の帯の滑らかな変化が無い | 規則 (背景は単色だけ) |
| タイルの目地の地と、山の形が無い | 規則 (背景の模様・clip-path が使えない。仮の画像は単色だけ) |
| PC の Hero がカンプより低く (約 660px 対 980px)、熱い が店名の横の小さな語になった | Claude の実装の選択 |
| SP で「ありま/す」と語の途中で折れる | Claude の実装 (`word-break` が許可一覧にあるかを確かめていない) |
| 1024・768: 横にはみ出し、巨大な文字が語の途中で折れる (fidelity-measure) | Claude の実装の誤り (PC と SP の2つの幅しか作らなかった) |

つぐ手と同じく、**カンプの表現の核の多く (境をまたぐ巨大な文字・縦書き・傾いた写真・湯気) は、今の実装レーンの規則では作れない。**
規則を緩めるのは、ここでは行わない。
