## 確かめたこと (リポジトリの外の使い捨ての道具)

320〜1920 の**全部の幅 (1px ごと、1601 幅)** を、JS 無効・通信遮断で、3つの書体の設定で描いて数えた。

- `ipa`: この容器の書体のまま (明朝は IPAMincho、ゴシックは Noto Sans CJK JP)。
- `alt`: 別の CJK 書体 (明朝の代わりに Noto Sans CJK JP、ゴシックの代わりに WenQuanYi Zen Hei。字の高さが 1.11〜1.26em)。
- `wide`: `@font-face` で IPA の字の高さを ascent 116%・descent 29% にした (CI の書体の高さに近づける。`gradient-harness.ts` の `withWideMetrics` と同じ)。

幅ごとに次を数えた。字の箱は文字ごとの Range の箱を 1.3em に切ったもの (墨より大きいので、数は多めに出る)。

1. 巨大な語・SVG の文字 (飾り) の字の箱が、ふつうの文字・事実の字の箱に重なる数と、いちばん近い距離。
2. 飾り (aria-hidden、飾りの SVG、::before・::after、板の縁取り・影・filter) を隠した描画との画素の差が、ふつうの文字・事実の字の箱の中に2画素以上ある文字。板の中の名札は、自分の板の絵と影はそのまま比べた。
3. 文字の点で `elementsFromPoint` が文字の上に描く別の要素を返す数 (板が文字を覆うか)。
4. 横のはみ出し、画面の端・切り抜く祖先を出る字、字の箱の地とのコントラスト (2 パーセンタイル、4.5:1、大きな字は 3:1)。

結果 (C d1-v5、1601 幅ずつ):

| 設定 | 字の箱の重なり (巨大な語) | 板が文字の上 | 画素の差 (飾り→文字) | はみ出し・切れ | 4.5:1 未満 | 巨大な語といちばん近い文字 |
|---|---|---|---|---|---|---|
| ipa | 0 | 0 | 27 幅: 601〜677 の 25 幅で tagline の1行目の箱の上端の1行に湯気の裾 (2〜5 画素)、1526・1730 (描き直すと 0、負荷の下の描画の揺れ) | 0 | 0 | 25px |
| alt | 0 | 0 | 368 幅: 320〜686 で 名前 ゆげ湯 (縦書き) の 1.3em の箱の左端が温度計の管に 8 画素、熱いほうから、 に湯気の裾 | 0 | 0 | 18px |
| wide | 0 | 0 | 783 幅: 320〜1100 で ゆげ湯 の箱の左端が温度計の管と目盛りに 16〜82 画素、熱いほうから、 に湯気の裾 | 0 | 0 | 18px |

湯気の裾は、601〜860 の湯気を 40px 上げて直した (`bottom: 470px`)。この直しの後の 601〜860 は**まだ掃引していない**。
ゆげ湯 の箱が温度計に届くのは、字の高い書体で縦書きの名前の箱が左へ広がるためで (墨より広い 1.3em の箱)、**直していない**。

前の版 (d1-v4) を同じ道具で測ると、1262 で す の上の板の画素 373、870 で 沸く と事実の字の箱の重なり、どの幅でも 15:00〜24:00 の下の火の光、601〜1100 で湯船の影が事実の1行目に、など。(前の版の全幅の数は取っていない。上は幅を選んだ測りである。)

**見たもの:** PC 1440 の全体 (0.28 倍、2列)、SP 390 の全体 (0.5 倍、4列) のカンプの描画。C を 1440・1262・1120・900・768・390・320 で前の版と並べて見た (0.25〜1 倍)。
