## 確かめたこと (リポジトリの外の使い捨ての道具)

320〜1920 の**全部の幅 (1px ごと、1601 幅)** を、JS 無効・通信遮断で、3つの書体の設定で描いて数えた。

- `ipa`: この容器の書体のまま (明朝は IPAMincho、ゴシックは Noto Sans CJK JP)。
- `alt`: 別の CJK 書体 (明朝の代わりに Noto Sans CJK JP、ゴシックの代わりに WenQuanYi Zen Hei。字の高さが 1.11〜1.26em)。
- `wide`: `@font-face` で IPA の字の高さを ascent 116%・descent 29% にした (CI の書体の高さに近づける。`gradient-harness.ts` の `withWideMetrics` と同じ)。

幅ごとに次を数えた。字の箱は文字ごとの Range の箱を 1.3em に切ったもの (墨より大きいので、数は多めに出る)。

1. 巨大な語・SVG の文字 (飾り) の字の箱が、ふつうの文字・事実の字の箱に重なる数と、いちばん近い距離。
2. 飾り (aria-hidden、飾りの SVG、::before・::after、板の縁取り・影・filter) を隠した描画との画素の差が、ふつうの文字・事実の字の箱の中に2画素以上ある文字。板の中の名札は、自分の板の絵と影はそのまま比べた。
3. 文字の点で `elementsFromPoint` が文字の上に描く別の要素を返す数 (板が文字を覆うか)。
4. 横のはみ出し、画面の端・切り抜く祖先を出る字、字の箱の地とのコントラスト (2 パーセンタイル、4.5:1、大きな字は 3:1)。

| ipa | 1601 (320〜1920) | 0 | 0 | 初回 4 (1315、1643、1758、1852) → 1幅ずつ描き直すと 0 (負荷の下の描画の揺れ) | 0 / 0 | 0 | 22px |
