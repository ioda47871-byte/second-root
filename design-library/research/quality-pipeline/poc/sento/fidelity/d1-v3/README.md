# ゆげ湯 d1 v3 — experimental_fidelity (研究専用、本番用ではない) (DEV-167)

2026-11-04。オーナーの指示「つぐ手・輪・ゆげ湯のカンプそのもののデザイン品質も引き続き改善する」と、
リードが C (d1-v2) の PC 1440・SP 390 の描画を見て挙げた直しによる。

- 前の版は `../d1-v2` で、そのまま残す。
- これは**カンプ `comps/d1-heat-descent-v2` の実装**である。カンプは前の C (d1-v2) の描き方を取り込んで作り直したので、
  この C はカンプと**同じ HTML・copy.json** を使い、CSS は先頭の注記だけが違う。描画はカンプと同じバイトになった。
- B方式の隔離された描画レーンを通る。本番の実装レーンの許可一覧は変えていない。**成功例の水準とは言わない。**

## 変えたこと

- **S1 のれんを夜の区画の主役に。** 見出し 湯上がりの、帰り道。を繰り返していた巨大な縁取りの 湯上がり を外し、文の記録からも消した。
  代わりに、のれんを SVG で大きく描いた (PC 540×500、タブレット 360・320、SP 300)。
  - 竿と端の飾り、4枚の布と布のあいだの切れ目、竿を通すふくろと縫い目、ひだの陰、少しずつ違ってたわむ裾。
  - 白い ゆ を1文字、布の形で切り抜き、切れ目が4つに割る (銭湯ののれんの印)。ゆ は創作の文として文の記録に足した。
  - のれんは竿ごと壁の区画の終わりにまたがる。見出しと情報には掛からない。のれんは飾り (`aria-hidden`) である。
- **S2 タイルの山の絵。** 空のグラデーション、雲、陰のある2つの山、水平線と水面の波を描き、上にタイルの目地を重ねた。
  写真の仮の板のまま (名札つき)。雪は描かない (前の版で外した)。

## 測ったこと

1440・390・1024・768 のどれでも、説明の行の覆い・横切り・巨大な語の折れ・横のはみ出しは 0 だった。温度計の覆いは 1.0 のまま。

**この計測の限界 (Fresh Review round 1 で分かったこと):** 説明の行の覆いと横切りは、行ごとに横の 20%・50%・80% の3点で`elementFromPoint` を引くだけなので、3px の線が点のあいだを通っても数えない (前の版の README は「`pointer-events: none` だから数えない」と書いたが、計測は `pointer-events` を戻して引いているので、それは理由ではなかった)。「語の途中の改行」は仕様の `words` (巨大な語) だけを数え、本文・事実の文は数えない。`caption_lines_total` が前の版より増えたのは、文に `<wbr>` を入れて文字の節が分かれ、計測が節ごとに行を数えるためで、行が増えたのではない。

### Fresh Review round 1 の L5・L3 と、いまの確かめ方

前の版の「上半分は変えていない」は、上半分の重なりをそのまま残していた。

- 390 で、縁取りの ぬるい の い が右の端で切れていた (140px)。112px にし、下へのはみ出しも合わせて 56px にした。
- 768 で、縁取りの 冷たい と 沸く が重なっていた (601 でも)。1101〜1300 でも 冷たい の い と 沸く の く が重なり、1101〜1199 では ぬるい の い が 冷 に重なった。
  巨大な語を幅で縮めた (PC: 熱い `min(470px, 32.65vw)`・ぬるい `min(280px, 19.45vw)`・冷たい `min(200px, 13.9vw)`・沸く `min(330px, 22.92vw)`、
  1100 以下: 熱い `min(330px, 30vw)`・ぬるい `min(200px, 25vw)`・冷たい `min(150px, 13vw)`、860 以下は 冷たい の上端を区画の頭から 120px (前は 90px) にし、火の区画の上の余白を 140px にした)。
  1440 の大きさは前と同じである。
- 1199 で、のれんが見出し 湯上がりの、帰り道。の 帰り道。に掛かっていた。のれんを `min(540px, 37.5vw)` に、見出しを `clamp(44px, 3.9vw, 56px)` にした。

  文に句の境の `<wbr>` を入れた (文の記録の文は変わらない)。

**Fresh Review の後に足した確かめ (リポジトリの外の道具、記録は下の表):** 線・巨大な語・飾りを隠した描画と隠さない描画の画素の差を取り、差が1文字ずつの箱に3画素以上入れば「文字の上に描いた」と数えた。本文と事実の文の行の切れ目を1文字ずつの位置から書き出し、句の途中で切れていないかを読んだ。そのうえで描いた画像を Read で見た。
巨大な語どうしは、1文字ずつの箱が重なるか、ページの端を越えるかも数えた。
確かめた幅は 1440・1199・1024・900・768・601・600・390 (重なりと文字の上の画素はほかに 1300・1250・1150・1101・1100・950・861・860・700・480・360) で、ほかの幅は確かめていない。
