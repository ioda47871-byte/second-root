2026-11-04。DEV-167 の後に残った弱さ (1024 でのれんの竿が壁の最後の行に近い、上半分の 熱い〜沸く の温度の旅が細い帯とぼんやりした光だけだった) を直した版。

- 前の版は `../d1-v3` で、そのまま残す。
- これは**カンプ `comps/d1-heat-descent-v3` の実装**である。この C はカンプと**同じ HTML・copy.json** を使い、CSS は先頭の注記だけが違う。描画はカンプと同じバイトになった。

## 変えたこと

- **温度計。** 前の版はページの全長に引いた 6px の帯で、色はページの % で決めたので区画の境とずれた。
  ガラスの管 (22px、SP 12px) と目盛り (24px ごとの短い印、120px ごとの長い印) にし、中の液の色を区画ごとに描いた (`section::before`)。
  色は区画の境で変わる: 熱い は白から朱、ぬるい は橙、冷たい は水色、沸く は燠の赤から明るい火、壁と夜は灰から紺。数は書かない。
- **湯気。** 前の版は湯気をぼんやりした光の楕円で描いていた。湯の面から立ちのぼる筋を SVG で描いた (`.wisps`、飾り、`aria-hidden`、`data-pa-role="decoration"`):
  ぼかした太い筋と細い筋が、上へ行くほど薄れる。PC は湯の表面の板の上から 熱い の い を通って立つ。1000〜1100 は湯船の板の上の縁から右に立つ。
  601〜999 はコピーが右の端近くまで来るので、熱い の上 (tagline より上) にだけ置いた。SP は lead と湯船の板のあいだの右に短く立つ。どの幅でもコピーに掛からない。
- **のれんの竿 (601〜1100)。** 壁の区画の下の余白を 110px から 170px にし、竿と壁の最後の行のあいだを約 80px にした (1024 では手ぬぐいの行の下 2px に箱が来ていた。いまは 62px)。

## 確かめたこと (リポジトリの外の道具、DEV-167 の道具を写して使った)

18の幅 (320・340・360・375・390・420・480・600・601・700・768・900・1024・1100・1199・1200・1300・1440) で次を数えた。

- 線・飾り・板 (影を切って) を隠した描画との画素の差を、1文字ずつの箱 (字送りの空きを除く) で数えた (飾りがふつうの文字の上に描いたか)。
- 巨大な語どうしの箱の重なりと、ページの端のはみ出し。ふつうの文字が画面の端を出るか。
- 文字の画素とその下の地のコントラスト (4.5:1、大きな字は 3:1)。
- 変えた所の幅で、本文と事実の文の行の切れ目を1文字ずつ書き出し、句の途中で折れていないかを読んだ。

そのうえで、描いた画像を Read で見た (下の「見たもの」)。ほかの幅は確かめていない。

結果: 飾り (巨大な語・温度計・のれん・湯気) がふつうの文字に掛かる字は 0。ふつうの文字で端を出るもの、4.5:1 を下回る小さな文字は 0。
板を隠すと数に出るのは、巨大な語 (ぬるい・冷たい) が庭の板に重なる所だけで、飾りどうしの構図である (前の版から)。
途中で 601〜900 の湯気の筋が tagline と lead に掛かり、lead が 1.4:1 まで下がったので、601〜999 は 熱い の上だけに置き直した (直した後に数え直して 0)。
行の切れ目は 320・390・601・768・1024・1100・1440 で前の版と同じだった。

**見たもの:** PC 1440 の全体 (0.28 倍)、SP 390 の全体 (0.5 倍)、上半分を 1440・1200・1024・768・390 (0.33〜0.6 倍)、温度計の区画の境を等倍、のれんを 1024 (0.5 倍)。
