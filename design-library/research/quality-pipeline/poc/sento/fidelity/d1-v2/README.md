## 直したこと

改良前の C は、上半分 (熱い→ぬるい→冷たい) にはリズムがあった。下半分 (火・タイルの壁・夜) は、地の色が変わるだけで平板だった (カンプ自身の `COMP_LOWER_HALF_FLAT` を、忠実に写していた)。

- **火 (沸く):**
  - 縁取りの巨大な文字「沸く」が、冷たい区画との境をまたぐ。
  - 区画の足もとに、熾火の赤い光のグラデーションを置いた。
  - 目盛りの帯を太くした。
- **タイルの壁:**
  - 山の絵の板を傾けて影を付け、火の区画の足もとへまたがせた。
  - 板にタイルの目地を描いた (飾りの ::after。文字は無い)。
  - **改良前の C が足していた雪を取り除いた** (カンプに無い、忠実さからの外れ)。
- **夜 (帰り道):**
  - 縁取りの巨大な文字「湯上がり」を置いた。
  - 文字の無いのれんの布 4 枚を、壁との境にまたがせた。
  - 電話を、朱の地の大きな枠にした。CP-003 の最後の区画の行動の案内 (錆色のボタン) にならった。
- **仮の板:** 写真の役割はそのままで、単色の斜線をやめた。湯面の波紋の質感 (CSS のグラデーション) と、白い縁と影を付けた。
  - **写真の代わりではない。** 事実を描いてもいない。
  - 湯船の板は、カンプの薄茶から、湯の青に変えた。カンプからの外れなので、ここに記録する。
- **新しい創作の文:** 「沸く」(既存の目盛りの語と同じ)、「湯上がり」。`copy.json` に creative_expression・owner_review_needed: true で記録した。数・温度・価格は使っていない。

## 残る問題 (隠さない)

- 写真は仮の板のまま。実際の写真が無いと、成功例のような写真と文字の重なりの質は判断できない。
- 山の絵は2つの三角の図のまま。タイルの目地を足しただけで、絵としては素朴である。
- 湯船の板の青は、カンプの薄茶と違う (上に書いた)。
- 「湯上がり」は、見出し「湯上がりの、帰り道。」と語が重なる。巨大な文字と見出しで語を繰り返す作りだが、くどく見えるかもしれない。
- 768 で、縁取りの「沸く」が冷たい区画の事実の行の近くまで来る (覆いはしない)。
- C は position・transform・グラデーション・SVG・writing-mode・text-stroke・負の margin・外側の影を使う。本番の実装レーンの許可一覧では通らない。
- 新しい創作の文は、オーナーの確認が要る。
