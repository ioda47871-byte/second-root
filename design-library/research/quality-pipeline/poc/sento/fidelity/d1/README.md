# ゆげ湯 d1: experimental_fidelity の実装 (C) (Issue #193 コメント `6596798696` の項3)

**研究専用で、本番の実装ではない。** 実装レーンの規則 (comp-impl の CSS 許可一覧) は変えていない。この実装は、その規則を通らないままである。

カンプ `comps/d1-heat-descent` (A) を、B方式の隔離された描画レーンの中で「実装」として作り直した。
- 安全の検査は `checkPrototype` で行う。
- 描画は JS 無効・通信遮断の `renderPrototype` で行う。
- `comp-lane.ts` は exit 0 で、問題は 0 件だった。
- 文の記録 `copy.json` は、カンプと同じ (`61ca0ddf…`)。

比べた3つ (どれも PC 1440・SP 390) を、Claude が並べて自分で見た。
- A: カンプ
- B: 規則の中の実装 `impl/d1-b`
- C: この実装

## カンプ (A) と違えた点 (実装としての条件)

- 区画の高さを中身で決めた。固定の高さを Hero の最低の高さだけにした。
- 区画に `data-comp-section` を付けた。`data-section` も残した。区画の箱は `renderPrototype` がこれで測る。
- 写真の仮の板に、カンプの比の `aspect-ratio` を付けた。
- 1024 と 768 でも崩れない (JS 無効で描いて目で見た)。測った結果は次のとおり。
  - 横のはみ出しは 0 である。
  - 文字の箱の重なり (飾りの巨大な文字を除く) は、1440・1024・768・390 で 0 である。
- 語の途中で改行しない。`keep-all` と、句の切れ目の `<br>` を使った。「ありま/す」は起きない。
- カンプの SP の不具合は写さなかった。カンプでは、湯船の板が朱の区画の下端の湯気を 60px 覆っていた。C では、湯船の板を暖の区画の中から始めた。

## 再現できたもの (A と同じに見える)

- 左端の温度計の帯。1本で途切れず、滑らかに色が変わる (グラデーション)。
- 縦書きの店名と、巨大な 熱い (縦書き、470px)。
- 縁取りの ぬるい が、暖と冷の境をまたぐ。縁取りの 冷たい は縦書きである。
- 傾いて影を落とす湯船の板。朱の区画の下端に乗り上げる。
- 湯気のにじみ、火の帯のグラデーション、タイルの目地、山の絵 (SVG。雪の頂を足した)。
- 夜の区画の大きな電話番号。

## 再現しなかったもの・残るもの

- カンプそのものの問題 (`COMP_LOWER_HALF_FLAT`) は、忠実に写したので残る。下半分は地の色の変化だけで、上半分より平板である。実装では直らない。
- 写真は仮の板のままである。
- 1024 と 768 では、表面の板を文の下へ移した。横に置くと文を覆うからである。カンプには無い幅なので、Claude の判断である。
- **本番に持ち込むには、規則の緩和が要る。** C が使っている性質は次のとおりで、どれも今の規則では拒まれる。
  - `position`・`transform`・`writing-mode`・`-webkit-text-stroke`
  - グラデーション・SVG・外側の影・負の margin

  緩めるかは、オーナーの別の承認による (コメント `6596798696`)。
