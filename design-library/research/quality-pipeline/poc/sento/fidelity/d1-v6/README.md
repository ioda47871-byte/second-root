## 変えたこと (600px 以下だけ。PC とタブレットの描画は前の版と同じ)

390 の 15:00〜24:00 では、刻みが数字の左に横棒として並び、−15:00 に読めた (`dev176/ev/s390-time-before.png`)。
夜の区画の情報の 時間 15:00〜24:00 も、同じ x から始まる。

- 文の左の余白 (`--gutter`) を 28px から 36px にした。

## 確かめたこと (リポジトリの外の使い捨ての道具)
