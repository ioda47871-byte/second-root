## 変えたこと (601〜860 だけ。ほかの幅の描画は前の版と同じ)

**なぜ届かなかったか。** 601〜860 では、文 (tagline と lead) が名前 ゆげ湯 の右 (x 270) から右の端の近くまで走っていた。湯気を湯船の板まで下ろすと文の上を通るので、前の版は湯気を 熱い の上 (区画の下から 470px) に短く置いていた。

- 文を名前の下の左の列へ移した (Hero の grid を1列に。SP と同じ組み)。tagline は x 100 から始まり、lead は幅 300px で2行に折れる (薪で沸かした湯を、毎日 / 入れ替えています。)。
- 右の列を空け、湯気を湯船の板の上の端 (区画の下から 104px、861〜999 と同じ) から 熱い の下まで 560px 立てた。幅は min(300px, 100vw − 470px) で、601 では 131px、768 では 298px。
- 名前・文・熱い・湯船の板の大きさは変えていない。
