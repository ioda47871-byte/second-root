## なぜ作ったか

d2-v1 は文の折り目を `<wbr>` で指定していた。サーバーの文章の検査 (`checkArtifactCopy`) は HTML の文字の断片 (text node) ごとに文章の記録と照らすので、
「7:00〜16:00」「名古屋市」などの断片を記録に無い文として読み、写真と文章の両方を持つ包み (`sales_demo_version_package_v2`) が作れなかった。
検査は緩めず、ページの側を直した。

## 何を変えたか

- index.html は カンプ `../../comps/d2-hearth-floor-v4` (A4) と同じバイト: `<wbr>` を全部外し、どの文も1つの文字のかたまりにした。所在地は区と町の間に空白を入れた
  (店名・道順と同じ折り目の置き方)。**写真の板の3つ組 (`fig-*` → `board-*` → `ph-*`) は d2-v1 と同じ。** copy.json は d2-v1 と同じバイト。
- style.css は d2-v1 のものの後ろに、折り返しの規則だけを足した: `word-break: keep-all` (前から) は読点・句点・空白でだけ折れるので、文ごとに
  N 字分の幅 (`ic` 単位 + 字間 .6px) を与え、N 字で句の切れ目に折れるようにした (窯の奥 12・薪 9・店先 13・粉 SP 9 / PC 14・架空の注記 15)。
- 行の組み方 (Chromium で 360・390・600・601・768・1024・1199・1440・1920 の全部の文の行を測り、はみ出しなし):
  - 窯の奥 石窯で焼くのは田舎パンと/バゲットです、薪 毎朝4時半に石窯へ/薪をくべます、店先 薪の石窯で田舎パンを焼き、/焼き上がった順に店先の棚へ/並べています。 (どの幅でも)
  - 粉 PC 粉は二種類を、/季節で割合を変えて合わせます、SP 粉は二種類を、/季節で割合を変えて/合わせます
  - 架空の注記 比較研究用の架空のパン屋です。/実在の店舗ではありません。、所在地は狭い幅で 名古屋市瑞穂区/架空町四丁目2-6
  - d2-v1 と違う所 (どれも句の切れ目): 粉の文の行の長さ、768 と 601 の店先の文、601 の窯の奥の文、SP の 架空季節のフルーツ/デニッシュ、所在地の空白
