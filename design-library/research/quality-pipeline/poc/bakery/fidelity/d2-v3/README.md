## オーナーの評 (Issue #290 P1) の各点と、何を変えたか

守ったもの (評の「強み」): **巨大な迫石のアーチに ほし窯 を入れた Hero と、その奥に石窯を覗く写真** (Hero の HTML は d2-v2 と同じバイト、PC の板の大きさも同じ)、
**PC と SP の別々の構図**、写真を自然に見せる板 (切り抜きは写真の形のまま)。窯の奥から扉へ冷めていく1枚の床 (節の境に線を引かない)、品名を格子に揃えないこと。
split hero・カードの列・汎用 LP には戻していない。「輪」の まわる も使っていない。

| 評 | d2-v2 | d2-v3 で変えたこと |
|---|---|---|
| **粉が弱い** | 1文と淡い点の円2つと帯1本。余白が働かない | 区画の主役を**器を真上から見た円の中の巨大な「粉」**にした (SVG の1つの文字、器の縁の内側に収まる)。字は**二つの粉の点** (粗い黄の点と細かい灰の点) で描き、左上から右下へ**斜めの帯で混ざる** — 「二種類を、季節で割合を変えて合わせる」(F11) を、段・目盛り・数を見せずに形にした (A2 で4つの段が「4つの配合」と読まれて落ちたので、数えられるものは置かない)。文は横に3行 (粉は二種類を、/季節で割合を/変えて合わせます) |
| **薪の火の文字演出** | 熱の輪と木口が飾りに見え、札 薪の火 は小さく木口の下 | 輪を**凡例のある図**にした: 札 薪の火 を**木口から引き出し線の先の板**に置き (図の中心が何かを名指す)、熱の輪は中心が太く濃く外へ細く薄く (熱の広がり)。PC では輪が**文の手前と区画の上端の手前で消える** (文の下に線を通さず、窯の奥との境に直線を出さない: 横と縦の2つの消え方を `mask-composite: intersect` で重ねる)。輪の数に意味は持たせない |
| **パンの品名まわりの重なり** | 架空田舎パン が写真の板に -6.25vw 重なる。棚の品名が棚板の縁をまたぐ | 架空田舎パン を**板の横に板の高さいっぱいの縦書き**にした (PC)。SP は板の下。棚の品名は**1枚ずつの棚板の上に立つ** (名の下端 = 棚板の上端、DOM で 0px)。バゲットの輪郭を字の em で測り (12em × 2.4em)、クープの線を**字と字の間に固定**した (どの書体でも) |
| **店舗情報が細かく単調** | 時間 16–46px、ラベル 12px #6b5038、架空の注記は最下部の 12px | 時間 22–44px (SP 24px 以上)、定休 20–34px、電話 28–44px (SP 30px)、所在地 18–22px、ラベル 13–15px (コントラスト 7:1 前後)。**架空の注記を店名のすぐ下の枠**に上げた (14–16px)。PC の扉は頁の下端に立つ (扉の外へ出る終わり方)。Hero の札も 14–18px |
| **記憶に残る書体が無い** | 全節に同じ「12px・左の罫」の札 | 節の札を**明朝の縦の柱**にして節ごとに置き方を変えた (窯の奥 = 写真の横の柱、店先の棚 = 棚板の吊り札、扉の外 = 扉の札、薪の火 = 図の板、粉 = 区画そのもの)。大きさの段: アーチの店名 78px → 節の主役 (器の中の粉の字・縦の品名 76px・薪の文 56px) → 事実の文 26–54px → 情報 16–22px → 札 15–19px |

折り返し: どの文も1つの文字のかたまりのまま (サーバーの文章の検査は文字の断片ごとに照らす)。`word-break: auto-phrase` (lang="ja") で句の間でだけ折り、
箱の幅を N.5 字 (前後に半字の余裕) にして、狙った句の切れ目で折れるようにした。店舗の情報は `keep-all` (時間は （ の前で折れる。auto-phrase だと 売り/切れ で割れた)。

## 実写真での確認 (2026-11-19、撮影済みの3枚。写真・描画・権利の記録はリポジトリの外)

オーナーの非公開アーカイブ (縮小した受け渡し版。原本の取り込み後の3枚と権利の記録はバイト一致) から、scratchpad に非公開の pipeline root を
**写して**組み、既存の差し替え (`swapPage`) で d2-v3 と d2-v2 を差し替えた。モデル・画像生成・新しい写真は使っていない。

- 差し替えの門 (権利・プロンプトの SHA・2倍・主役の箱・3つ組・横のはみ出し・boards_intact): d2-v3、d2-v2 とも通過。倍率の例外なし
- d2-v2 の再現: 切り抜き (PC・SP)・HTML・CSS は worker の出力と**バイト一致**。受け渡しで省かれたタブレットの切り抜き2枚も、作り直したものが原本の SHA256SUMS と一致。
  描画の差は画素の 1.9% (PC) / 4.0% (SP) で、書体の違い (ゴシックの役)
- 実写真のページで9幅の計測 (scratchpad、JS 無効・通信遮断): d2-v3 は全幅で所見 0 (区画の境の切れ・はみ出し・重なり・12px 未満・切れ 0、コントラスト最小 5.05)。
  d2-v2 は全幅で所見あり (上の「検査と描画」と同じもの)
- 実写真を見て直したこと (板の大きさ・形と言葉は同じ): 田舎パンの写真は縁が暗く地に溶けたので、板の外に焼き色の細い縁と影を付けた。描いた木口は
  Hero の写真の火の横で漫画に見えたので、焦げた木口の色にした。薪の火から店先への地の変わり目が帯に見えたので、中間の色を足して長くした
