# ほし窯 d2 v1 — 研究専用の忠実な実装 (C、`experimental_fidelity`) (DEV-139)

2026-11-17。輪 (SR-001) の作り方 (カンプ → C ページ → 写真の枠の計測 → 写真の指示書) を、架空のパン屋 ほし窯 の方向 `d2-hearth-floor` でオフラインに通したもの。
**本番用の実装ではない。成功例ではない。** オーナーはまだ見ていない。写真はすべて仮の板 (`placeholder_limited`)。

## 何から作ったか

- カンプ `../../comps/d2-hearth-floor` (A)。`comp-lane.ts` の描画と検査、`comp-copy.ts --audit` (round 0 で `approve_candidate`)、Claude の見比べ `review.json` (2巡、判定 `show_owner`) を通った。
- **index.html と copy.json はカンプと同じバイト。** 事実と文は足していない・変えていない。
- style.css は、Hero (窯の口のアーチの舞台、`vw` で幅に比例) までカンプと同じで、その下の区画を作り直した:
  - PC (≥601) の区画を 12 列の格子に置き、高さは中身で決まる (カンプは区画の高さを `vw` で固定し、要素を絶対配置していた)
  - 飾りの層 (熱の輪と木口、棚板、粉の点、扉の線) は流れの上に重ね、幅に比例させる
  - SP (≤600) はカンプと同じ
- 写真の板の形は、`<div class="fig …">` の直後に `<div class="board …"><div class="photo"></div></div>`、その直後に `<p class="ph …">写真｜…</p>` (輪と同じ並び。`photo-slots.ts` がこの札から枠を探す)。

## まだ残ること

- 写真はすべて仮の板。写真の生成・取得は別の承認が要る (指示書の草案は未承認)。
- この容器には明朝体が無く、明朝体の指定は IPAGothic などで描かれている。
- 写真の差し替え (`photo-swap-shops.ts`) に ほし窯 は入れていない (差し替えの道具は店ごとの承認と一緒に足す)。
- 自己批評の残り (Hero の左の面が静か、床を真上から見る読みが札に頼る、など) はカンプの `review.json` の `remaining`。
