# 輪 d1 v4 — experimental_fidelity (研究専用、本番用ではない) (DEV-168)

2026-11-04。DEV-167 の後に残った弱さ (601〜999px で駅が格子に並びスポークにつながらない、締める の る が右の端で切れる) を直した版。

- 前の版は `../d1-v3` で、そのまま残す。
- これは**カンプ `comps/d1-wheel-hub-v3` の実装**である。この C はカンプと**同じ HTML・copy.json** を使い、CSS は先頭の注記だけが違う。描画はカンプと同じバイトになった。

## 変えたこと

- **タブレット (601〜999px) の駅をスポークに吊った。** 前の版はこの幅で駅が12列の格子に並び、PC と SP の主題 (車輪のスポークの先に修理がある) が切れていた。
  Hero の車輪とハブはこの幅でも PC と同じ位置 (ハブは右上、区画の頭より上) にあるので、ハブの縁から4本のスポークを PC と同じ墨の縁つきの太い黄で引き出し (`.reach-tab`、飾りの SVG)、
  各板の右上のピンへ届かせた。板は左上から右下へ段に下る (振れ取り → パンク → チェーン → ブレーキ)。後のスポークほど急で、先の板と名前の右を通るので、スポークは板にも名前にも掛からない。
  板はピンを軸に少し傾き、写真の名札は板の左下に貼る (1000 以上と同じ作り)。名前は板の下。見出し スポークの先に、修理がある。は左下の空いた所、まわる は区画の下の左。
  位置は 768 の座標を vw にしたので、601〜999 で同じ構図が縮む。
- **締める を全部見せる。** る がどの幅でも右の端で 10〜20px 切れ、意図した端越えではなく切れに見えた。右の端から 1.4vw (SP 10px) 内に入れ、SP では大きさを幅で縮めた (`min(110px, calc(30vw - 10px))`)。
  320〜1440 で字の箱が端を出ない。まわる は1文字目の半分が左の端から出る、意図した端越えのまま残した。

## 確かめたこと (リポジトリの外の道具、DEV-167 の道具を写して使った)

18の幅 (320・340・360・375・390・420・480・600・601・700・768・900・1024・1100・1199・1200・1300・1440) で次を数えた。

- 線・飾り・板 (影を切って) を隠した描画との画素の差を、1文字ずつの箱 (字送りの空きを除く) で数えた (飾りがふつうの文字の上に描いたか)。
- 巨大な語どうしの箱の重なりと、ページの端のはみ出し。ふつうの文字が画面の端を出るか。
- 文字の画素とその下の地のコントラスト (4.5:1、大きな字は 3:1)。
- 変えた所の幅で、本文と事実の文の行の切れ目を1文字ずつ書き出し、句の途中で折れていないかを読んだ。

そのうえで、描いた画像を Read で見た (下の「見たもの」)。ほかの幅は確かめていない。

結果: ふつうの文字で端を出るものは 0。飾りがふつうの文字に掛かるのは、スポークが ハブ の円の縁で 輪 の字の箱に入る所だけ (前の版から、字には掛からない)。
4.5:1 を下回る小さな文字は 0。板を隠すと数に出るのは、601 以上で板に貼った写真の名札 (板の上に暗い地で載せた札。文字の画素の下の地と比べて 601〜999 で 8.2:1 以上) だけである。
タブレットの見出し・名前・情報の行の切れ目は、601・700・768・900・999 で句の境だけだった。

**見たもの:** PC 1440 の全体 (0.28 倍)、SP 390 の全体 (0.5 倍)、タブレットの駅の区画を 601・768・900・999 (0.4〜0.5 倍)。
