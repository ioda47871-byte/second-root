# 輪 d1 v3 — experimental_fidelity (研究専用、本番用ではない) (DEV-167)

2026-11-04。オーナーの指示「つぐ手・輪・ゆげ湯のカンプそのもののデザイン品質も引き続き改善する」と、
リードが C (d1-v2) の PC 1440・SP 390 の描画を見て挙げた直しによる。

- 前の版は `../d1-v2` で、そのまま残す。
- これは**カンプ `comps/d1-wheel-hub-v2` の実装**である。カンプは前の C (d1-v2) の描き方を取り込んで作り直したので、
  この C はカンプと**同じ HTML・copy.json** を使い、CSS は先頭の注記だけが違う。描画はカンプと同じバイトになった。
- B方式の隔離された描画レーンを通る。本番の実装レーンの許可一覧は変えていない。**成功例の水準とは言わない。**

## 変えたこと

- **B1 スポークの先の駅。** PC では、Hero の車輪の4本のスポークを、ハブの縁 (輪 の円の外) から各駅のピンまで、
  墨の縁つきの太い黄の1本の線で引き出した。リムを越えてまっすぐピンに届く。他のスポークは細い黒のまま。
  SP では車輪を 0.8 にして上げ、ハブから1本のスポークを黄で左下へ引き出し、タイヤの外のピンで曲げて縦の背骨にした。
  振れ取りとブレーキの腕も背骨まで伸ばした (前の版は離れていた)。
- **B2 名札と板。** 振れ取りの板は、格子の版の縦長の比が PC にも残っていた。PC の比を横長 (260:200) にし、傾きを抑え、
  名札を板の下へ離した。4つの名札はどれも板にもスポークにも掛からない。駅の写真の名札は 12px にした。
- **B3 巨大な語。** 太い字の縁取りは字の重なりまで描き、三重の線に見えた。まわる は塗りにし、暗い地では黄、黄の地へはみ出した部分は墨。
  締める は墨の塗り。SP の まわる は背骨の右へ移した。
- **B4 SP の見出し。** 見出し まがった車輪も、まっすぐに。を車輪の下の地の上へ移した。線は文字を横切らない。
  見出しは背骨の右に寄せた。

## 測ったこと

1440・390・1024・768 のどれでも、説明の行の覆い・横切り・巨大な語の折れ・横のはみ出しは 0 だった。
核 (車輪の絵の箱) の覆いは前の版と同じ (PC 0.616、SP 0.365)。線と文字の関係は描いた画像を見て確かめた。
