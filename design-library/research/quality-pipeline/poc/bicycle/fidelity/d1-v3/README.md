# 輪 d1 v3 — experimental_fidelity (研究専用、本番用ではない) (DEV-167)

2026-11-04。オーナーの指示「つぐ手・輪・ゆげ湯のカンプそのもののデザイン品質も引き続き改善する」と、
リードが C (d1-v2) の PC 1440・SP 390 の描画を見て挙げた直しによる。

- 前の版は `../d1-v2` で、そのまま残す。
- これは**カンプ `comps/d1-wheel-hub-v2` の実装**である。カンプは前の C (d1-v2) の描き方を取り込んで作り直したので、
  この C はカンプと**同じ HTML・copy.json** を使い、CSS は先頭の注記だけが違う。描画はカンプと同じバイトになった。
- B方式の隔離された描画レーンを通る。本番の実装レーンの許可一覧は変えていない。**成功例の水準とは言わない。**

## 変えたこと

- **B1 スポークの先の駅。** PC では、Hero の車輪の4本のスポークを、ハブの縁 (輪 の円の外) から各駅のピンまで、
  墨の縁つきの太い黄の1本の線で引き出した。リムを越えてまっすぐピンに届く。他のスポークは細い黒のまま。
  SP では車輪を 0.8 にして上げ、ハブから1本のスポークを黄で左下へ引き出し、タイヤの外のピンで曲げて縦の背骨にした。
  振れ取りとブレーキの腕も背骨まで伸ばした (前の版は離れていた)。
- **B2 名札と板。** 振れ取りの板は、格子の版の縦長の比が PC にも残っていた。PC の比を横長 (260:200) にし、傾きを抑え、
  名札を板の下へ離した。4つの名札はどれも板にもスポークにも掛からない。駅の写真の名札は 12px にした。
- **B3 巨大な語。** 太い字の縁取りは字の重なりまで描き、三重の線に見えた。まわる は塗りにし、暗い地では黄、黄の地へはみ出した部分は墨。
  締める は墨の塗り。SP の まわる は背骨の右へ移した。
- **B4 SP の見出し。** 見出し まがった車輪も、まっすぐに。を車輪の下の地の上へ移した。線は文字を横切らない。
  見出しは背骨の右に寄せた。

## 測ったこと

1440・390・1024・768 のどれでも、説明の行の覆い・横切り・巨大な語の折れ・横のはみ出しは 0 だった。
核 (車輪の絵の箱) の覆いは前の版と同じ (PC 0.616、SP 0.365)。

**この計測の限界 (Fresh Review round 1 で分かったこと):** 説明の行の覆いと横切りは、行ごとに横の 20%・50%・80% の3点で`elementFromPoint` を引くだけなので、3px の線が点のあいだを通っても数えない (前の版の README は「`pointer-events: none` だから数えない」と書いたが、計測は `pointer-events` を戻して引いているので、それは理由ではなかった)。「語の途中の改行」は仕様の `words` (巨大な語) だけを数え、本文・事実の文は数えない。`caption_lines_total` が前の版より増えたのは、文に `<wbr>` を入れて文字の節が分かれ、計測が節ごとに行を数えるためで、行が増えたのではない。

### Fresh Review round 1 の L1・L3 と、いまの確かめ方

- **L1 作業台の名札。** 写真｜作業台と自転車 (12px、`#5d6066`) は、板の落とす影の上で 2.5〜4.4:1 だった
  (`filter: drop-shadow` の板は、流れの中の文字より上に塗られるので、影が名札に掛かる)。名札を板より上の層に置き、
  コンクリートの地の帯に乗せ、墨の文字にした。8つの幅で、文字の画素の下の地と比べて 13.5:1。
- **L3 語の途中の改行。** 前の README の「語の途中の改行 0」は、巨大な語 (まわる・締める・輪) だけを数えた結果だった。
  本文と事実の文は、768 で 架空町四丁|目8-1・徒|歩3分、1440 で 締め|て・直|します、390 で 作業|台 と割れていた。
  文に句の境の `<wbr>` を入れ (文の記録の文は変わらない)、`h1, h2, p, dd` に `word-break: keep-all; overflow-wrap: anywhere` を掛けた。
  601 の見出しは まがった|車輪も、と折れる (前は 、 が行の頭に来た)。
- **線と文字。** 車輪の振れ取り の名札の り の右に黄のスポークが数 px で迫っていたので、名札を 1vw 左へ寄せた。
  スポークが 輪 の字の箱に入るのはハブの円の縁で、字には掛からない。

**Fresh Review の後に足した確かめ (リポジトリの外の道具、記録は下の表):** 線・巨大な語・飾りを隠した描画と隠さない描画の画素の差を取り、差が1文字ずつの箱に3画素以上入れば「文字の上に描いた」と数えた。本文と事実の文の行の切れ目を1文字ずつの位置から書き出し、句の途中で切れていないかを読んだ。そのうえで描いた画像を Read で見た。
確かめた幅は 1440・1199・1024・1000・999・900・768・601・600・390 (行の切れ目と線は 1440・1199・1024・900・768・601・600・390) で、
ほかの幅は確かめていない。

### Fresh Review round 2 の H1・L4

- **H1 狭い SP で文字が右の端で切れていた (前の版 d1-v2 から)。** 360 では 車輪の振れ取り (40px) の り が 16px、
  縦の見出し どこを直すか、先に決める。の全部の字が 4px 切れ、375 でも り が 1px 出ていた。380 以上は切れない。
  修理の名札を `min(40px, calc(13.7vw - 12.5px))`、一本ずつ。を `min(60px, calc(18vw - 2px))`、SP の まわる を `min(100px, calc(34vw - 20px))`、
  電話を `min(40px, calc(12vw - 4px))` (折らない) にし、作業台の格子の板の列を `minmax(0, 240px)` にして、狭いときは板が先に縮む。390 の大きさは前と同じ。
- **L4 600 でパンク修理の板の角が名札に重なっていた。** -4deg の板は幅が広がるほど左下の角が下がる。名札の上の空きを
  `max(10px, calc(4.2vw - 6.5px))` にした (390 は 10px のまま)。板の影を切った描画で、320〜600 の板と名札の重なりは 0。

**Fresh Review round 2 の後の確かめ (19の幅: 320・340・360・375・380・390・420・480・540・600・601・700・768・900・1024・1100・1199・1300・1440):** 線・飾り・板 (影を切って) を隠した描画との画素の差を、1文字ずつの箱 (字送りの空きを除く) で数えた。巨大な語どうしの箱の重なりと端のはみ出し、ふつうの文字が画面の端を出るか、文字の画素とその下の地のコントラスト (4.5:1、大きな字は 3:1) も数えた。320・360 の全体と、直した所の切り抜きを Read で見た。
結果: ふつうの文字で画面の端を出るものは 0。線が字に掛かるのは、スポークが ハブ の円の縁で 輪 の字の箱に入る所だけ (字には掛からない)。
1000 以上で写真の名札が板の上に載るのは、板に貼った札としての作り。端を越えるのは飾りの 締める (右) と まわる (601 以上で左) だけである。
