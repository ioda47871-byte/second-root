2026-11-03。`../d1` (C v1) を直した版である。B方式の道 (`checkPrototype`、JS 無効、通信遮断の描画) を通る。
本番の実装レーンの許可一覧には通らない (position・transform・SVG・writing-mode・text-stroke・グラデーション・clip-path を使う)。

**成功例の水準とは言わない。** オーナーが画像を見るまで判断しない。写真は仮の板のままである。

## 直したこと (Claude が PC 1440・SP 390・1024・768 の描画を見て、2巡で)

- **核を図にした: 修理の駅がスポークの先に付く。**
  - PC: Hero の車輪のハブ (この区画の座標で x 1120, y −320) から、4本のスポークがリムを越えて暗い区画へ伸びる。それぞれの先の黄色いニップルから、修理の板が吊り下がる。
    - スポークの角度は 152°・133°・114°・94°。板はスポークに沿って少し傾く。
    - v1 では、板は車輪とつながらずに散らばっていた。
  - SP: 車輪の左下から1本のスポークがページを下り、各駅は短い腕とニップルでそこに吊られる。
  - 1024: PC と同じ扇。768 (601〜999px): v1 の格子のまま (扇は無い)。
- **黄の地で消えた「まわる」:** 縁取りを2枚重ねにした。暗い地の上は黄、黄の地にはみ出した部分は墨の縁取りである (clip-path で切り分け)。
- **暗い区画の高さ:** v1 は 1771px で、カンプ A の 1500px より高かった。v2 は 1180px にした (扇に収まる高さ)。ページ全体は 5883px から 5292px になった。
- **SP で切れていた「輪」:** 車輪の中心を x 330 から x 250 (390 のうち) に移した。ハブと「輪」の円が画面の中に収まる。
- **仮の写真の板:** 光の当たりと影のぼかし、内側の細い枠を足した。駅ごとに板の色味を少し変えた。写真に見せかけた絵や、事実を描いた絵は入れていない。
- 見出し「スポークの先に、修理がある。」は1行に収めた (v1 は「る。」が1文字だけ次の行に残った)。

## 2巡のあいだに見つけて直したこと

- 1巡目: 振れ取りの板が、パンクの板に重なった。扇の角度とスポークの長さを、駅ごとに変えた。
- 2巡目:
  - 写真の名札がニップルに重なった。名札を板の右下に移し、振れ取りの板だけは右上に置いた。
  - 「車輪の振れ取り」が、別のスポークと板に掛かった。左下へ動かした。
  - 768 で、「車輪の振れ取り」が「まわる」に触れた。区画の下の余白を 19vw から 26vw にした。

## 残る問題 (隠さない)

- 写真はすべて仮の板である。実際の写真が無いので、成功例の水準は判断できない。
- 768 (601〜999px) では、駅は v1 の格子のままで、スポークにつながらない。
- 扇の配置は、1440 の座標を vw で伸び縮みさせている。1000〜1100px では、文字の最小の大きさ (26px) との兼ね合いで、ラベルが板に近づく。

- 振れ取りの板の名札だけ、右上にある (ニップルを避けたため)。
- 創作の文 (キャッチ・見出し・まわる・締める・写真の名札) は、オーナーの確認が要る。
