## 変えたこと

- **スポークとハブ (PC 1000 以上、SP 600 以下)。** 内の端がハブ (輪 の黄の円) の縁の手前で切れていた。
  - PC は 1440 幅の単位で 8、画素で 5.6〜10.8px。
  - SP は 390 幅の単位で 5.6、画素で 4.6〜8.6px。

  ハブの中心と半径は、どちらの SVG の単位でもどの幅でも一定である。PC は (1119.97, −320.06) で半径 149.98。SP は (249.98, 329.74) で半径 54.40。
  だから始点を、線の上の「中心から半径 + 0.5 単位」の点に移し、端を四角にした (タブレットの d1-v5 と同じ作り)。外の端はピンの下に隠れる。
- **PC の駅の板の影。** 24px 下・22px のぼかしの影が、ブレーキ調整 (1000〜1920) と チェーン交換 (1000〜1300) の下に入っていた。
  - 影を 10px 下・8px のぼかしにした。
  - ブレーキ調整 を 16px 下げた。
- **PC の 車輪の振れ取り。** 別の CJK 書体 (alt) で、車輪の振れ取り の最後の字が2本目のスポークに 3px 掛かっていた (1000〜1200)。写真の札 写真｜ も1本目のピンに 2px 掛かっていた (1000)。どちらも前の版からある。
  - 名前を 1.4vw 左へ移した。
  - 札を板の上の端から下の端へ移した。
- **SP の駅の板の影。** 影が、写真の札・駅の名前の下に入っていた (320〜600 のどの幅でも)。
  - 影を 8px 下・6px のぼかしにした。
  - 札を暗い地の帯 (`--asphalt`) に乗せ、影より前にした (作業台の札と同じ作り)。
- **SP の作業台 (HOLD 6)。** 作業台の板の影を 12px 下・8px のぼかしにした。縦の事実の列の前に 8px を足した (足りない幅では板が 8px 細くなる)。

**スポークとハブの距離。** ハブの縁からスポークの内の端までを 320〜1920 の 1px ごとに測った (+ はハブの外)。

| 前 (d1-v5) | 4.6〜8.6px | 0.14〜0.85px | 5.6〜10.8px |
| **この版** | 0.4〜0.77px | 0.14〜0.85px (変えていない) | 0.32〜0.75px |

**掃引。** 320〜1920 の全部の幅 (1px ごと、1601 幅) を、3つの書体の設定で数えた。設定と数え方は ゆげ湯 d1-v5 の README と同じである。

- `ipa`: この容器の書体
- `alt`: 明朝を Noto Sans CJK JP、ゴシックを WenQuanYi Zen Hei に
- `wide`: ascent 116%・descent 29%

| 設定 | 幅 | 巨大な語の字の箱の重なり | 板・要素が文字の上 | 画素の差 (飾り→文字) | はみ出し / 切れ | 4.5:1 未満 | 巨大な語といちばん近い文字 |

| ipa | 1601 (320〜1920) | 0 | 0 | 1601 (すべて 輪 の字の箱の角。墨では 0。HOLD 1) | 0 / 0 | 0 | 27px |
| alt | 1601 (320〜1920) | 0 | 0 | 1601 (すべて 輪 の字の箱の角。墨では 0。HOLD 1) | 0 / 0 | 0 | 11px |
| wide | 1601 (320〜1920) | 0 | 0 | 1601 (すべて 輪 の字の箱の角。墨では 0。HOLD 1) | 0 / 0 | 0 | 7px |

区間ごとの数 (どの区間も、画素の差は 輪 の字の箱の角だけ。ほかは 0):

| 区間 | ipa の最小距離 | alt | wide |
