# 輪 d1: 研究専用の忠実な実装 (C、`experimental_fidelity`)

2026-11-03 (DEV-160、Issue #193 コメント `6596798696` の 3)。

**本番用の実装ではない。** 実装レーンの規則 (`comp-impl` の CSS と HTML の許可一覧) は変えていない。
この実装はその規則の外にあり、隔離された B方式の描画レーンで描く。
`comp-lane.ts` の `checkPrototype` を通り、JS 無効・通信遮断の `renderPrototype` で描いた。
規則の違反を隠して合格にしたものではない。

## 何を確かめたか

カンプ `comps/d1-wheel-hub` (A) の核を、**実装として**再現できるかを確かめた。

- **区画の中身は格子と流れで置き、高さは中身で決まる。** Hero だけは図が主役の舞台で、幅に比例する (`vw`)。
- **飾りの層は流れの上に重ねる。** 対象は、車輪、縁取りの巨大な文字、空気入れの目盛り、傾いた板。
- **区画には `data-comp-section`** (実装の属性) **と `data-section`** (`comp-lane` が区画を測る属性) **を付けた。** 値は同じである。
- **写真は仮の板のまま。** 縦横比はカンプと同じにした。

## Claude が画像を見て確かめたこと (A|B|C を PC・SP・1024・768 で並べた)

**再現できたこと (B で失われ、C で戻ったもの)**

- 放射状の32本のスポークの車輪が、Hero から暗い区画へまたがる。
- 縁取りの巨大な文字 まわる と 締める が、区画の境をまたぐ。
- 4つの修理の板が傾き、影を落とし、千鳥に並ぶ。
- 作業台の区画の縦書き。
- 空気入れの目盛りと斜めの針が、区画の境に掛かる。
- 来店の車輪が画面の外へはみ出す。
- SP で車輪が先、文が後 (カンプの順)。
- SP の まわる が1行のまま (B の まわ/る の折れが無い)。

**直した点** (カンプからの意図的な差。記録する)

- SP の Hero で、文の地の箱が車輪を四角く切っていた (カンプの `COMP_ELEMENT_COVERS`)。行ごとの地の帯に変え、車輪が丸く見えるようにした。
- PC で 一本ずつ。 が 一本ず/つ。 と折れた (C の1巡目の誤り)。nowrap で直した。
- 1024 と 768 で、Hero の説明の文が車輪のタイヤを横切った。文の幅を絞って直した。
- まわる が 車輪の振れ取り の文字に重なった。区画の下の余白を広げて直した。

**直していない点 (カンプの問題を、そのまま写した)**

- 黄の縁取りの まわる が、黄の地の上で見えなくなり、切れて見える (カンプの `COMP_OUTLINE_LOST_ON_GROUND`)。
- スポークの先に修理の駅が付く核が、図になっていない (カンプの `COMP_CORE_NOT_DRAWN`)。板はスポークにつながらない。
- 写真は仮の板のまま。

**C の残る差**

- PC の暗い区画が、カンプより高い (C の区画は 1858px、カンプは 1500px)。まわる と文字の重なりを避けたためである。
