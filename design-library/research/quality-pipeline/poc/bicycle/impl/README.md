## a: 規則の中で素直に組んだ版。見て分かった低下

- **車輪が空の輪になった。** スポークが無く、ボタンのように見える。店の物 (車輪) が読めない。規則で SVG・斜めの線・transform が使えないことが原因。
- **車輪が Hero の中に収まった。** 右にはみ出して暗い区画へまたがる構図が消えた。規則で position・overflow・負の margin が使えないことが原因。
- **4つの修理が 2×2 の同じ大きさの板の格子になった。** 汎用の grid_cards に近い。これは Claude の実装の選択による。
- 縁取りの巨大な文字は、低い明暗差の塗りになった。区画の境もまたがない (規則)。
- 作業台の区画の縦書きは横書きになった (規則)。

## b: 低下を直した版 (規則はそのまま)

- **車輪にスポークを描いた。** 縦と横の4本だけで、内側の灰の輪もある。帯の右罫と腕の線で描き、ハブの黄色い円に店名を乗せた。車輪として読める。
- **修理を格子でなくした。** 3列の格子で、板と修理名の左右・大きさ・高さを駅ごとに変えた。

## まだ残る低下と、その出所

| 低下 | 出所 |
|---|---|
| スポークが4本だけで、放射状にならない | 規則 (SVG・斜めの線・transform が使えない) |

| 縁取りの巨大な文字が無い。境もまたがない | 規則 (`-webkit-text-stroke`・position が使えない) |
| 縦書きが無い | 規則 (横書きだけ) |
| 空気入れの目盛りが無く、針も水平の棒 | 規則 (斜めの線・SVG が使えない) |

| 写真が単色の板 | 規則。実際の写真は別の承認が要る |
