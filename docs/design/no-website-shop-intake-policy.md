# Second Root｜新規研究店舗は「独立したWebサイトを持たない店」に限定

**ユーザー指示:** 2026-10-28「成功例とします、あと調べるのはウェブサイトがない店でお願いします」。CP-019までの既存研究事例を遡及削除せず、**CP-020以降の新規店舗探索**と、可能性があれば営業候補選定に適用。これは**研究の店舗選定規則**であり、本番営業AIに自動適用するコードではない。

## 「Webサイトなし」とみなす範囲

- **候補にできる:** Instagram/X/TikTokなどSNS、Googleマップ、食べログなど第三者掲載ページのみが見つかり、**独立した本人管理の公式ホームページやネットショップが検索で見つからない**店。
- **候補から外す:** 自社ドメインの公式サイト、サブドメイン上の公式ランディングページ、BASE/STORES/Shopifyなどの**公式ネットショップが1つでもある**店。公式サイトの質が低い/更新が古いだけでも「サイトなし」と数えない。
- **不明として保留:** 店名の表記揺れ/同名店との混同、公式SNSのリンク先未確認、旧Webの存続疑い、閉店疑い、事業主体の不一致。確認せず「サイトなし」と断定しない。
- 外部のイベント出店者紹介やGoogleビジネスプロフィールは公式の独立したサイトではないが、そこに公式Webリンクがあれば開いて判定する。
- **「見つからなかった」≠「存在しない」**。調査では`WEB_NOT_FOUND_AFTER_CHECKS`のような発見結果と検索日、出典を記録し、未発見は事実上の不存在証明として宣伝しない。最終営業前には公式アカウント等へ追加確認する。

## 必須の候補調査チェック

1. 実在店舗・活動継続を2026年に近い資料で確認。正式店名、所在地/活動地、業種、公式SNSの同一性。
2. 検索① `"正式店名" 公式サイト`、検索② `"正式店名" ホームページ URL`、検索③ `"正式店名" 通販 BASE STORES Shopify`、検索④ `"Instagramアカウント" website link`、検索⑤ 名称の表記揺れ・住所・電話番号で企業サイトが無いか調べる。
3. 公式SNSのプロフィール/リンク集で外部リンク先を確認（アクセスできない場合は`LINK_IN_BIO_UNVERIFIED`の保留）。第三者の紹介に`HP`欄や`公式サイト`欄がないか調べる。
4. 他社プラットフォーム内の**本人のショップ**（BASE等）が発見されたら、独立ドメインがなくても`EXCLUDE_OFFICIAL_WEB_SHOP`。SNSのみと第三者掲載のみなら、根拠日付付きで`WEB_NOT_FOUND_AFTER_CHECKS`に進める（調査限界を明記）。
5. 身元の正しさ・実店舗営業形態・情報の現在性も別に検証し、画像生成前のIdentity Lockと権利確認を行う。候補の初稿を勝手に営業DMに送らない。
6. 実際のサイトが後から見つかったら研究候補の選定判定を修正。既にユーザーが採用した研究作品の歴史的採用は取り消さず、今後の営業候補から外す。

## CP-020候補（まだ研究成功例ではない）

**喫茶 ITALICO**（名古屋市中村区名楽町2-1、2026-10-17開業として第三者資料に掲載）、Instagram `https://www.instagram.com/kissa.italico/`。食べログ `https://tabelog.com/aichi/A2301/A230113/23098182/` は公式アカウント欄にInstagramのみを表示し、複数の店名＋Web/ホームページ/Instagram検索でも本人独立ドメインやBASE/STORESを発見できなかった。

**暫定判定:** `WEB_NOT_FOUND_AFTER_SEARCHES__LINK_IN_BIO_UNVERIFIED`。SNSプロフィールの外部リンク先を直接確認できていないため、**Webサイト不存在を確定したのではない**。正式なCP-020の制作/営業採用に進む前に公式プロフィールリンクと事業者サイトを再確認。第三者掲載の営業時間・メニューは未検証の現況として扱わない。

## 安全境界

このチェックはGitHubの研究資料のルールであり、DB更新、自動営業送信、既存コード変更、実際の店の同意取得、本番マージやWeb公開を行わない。研究成功の累計はCP-019採用で18件、参考候補80件、目標30件まで12件。
