### 2.2 DEV-083 に足したい小さな項目

**N1. 装飾の SVG を、ハッシュで照らす画像の資産として許す (インラインの SVG は許さない)**

- DEV-083 では、SVG の図は段 F の「アイコン」で、`img` の資産に限られている。
- 3店の核 (割れ目の線、スポーク、山) は大きな装飾の図で、文字を持たない。だから、早い段で同じ形で許したい。
  - `assets.json` に新しい種類 `decoration_svg` を足す。
  - `<img>` でだけ置き、役割は `decoration` とする。
- **厳しい SVG の構文検査**を設ける。
  - 許す要素: `svg`・`g`・`path`・`line`・`polyline`・`polygon`・`rect`・`circle`・`ellipse`・`linearGradient`・`radialGradient`・`stop`
  - 許さない要素: `text`・`tspan`・`foreignObject`・`image`・`use`・`script`・`style`・`animate*`・`set`・`a`・`filter`
  - 許さない属性と値: `href`・`xlink:href`・`on*`、`url(` (同じファイル内の `#id` のグラデーションの参照だけは例外)、`data:`
  - 大きさの上限を設ける。
- `img` で読み込んだ SVG は、ブラウザが scripts と外への読み込みを止める。今の routing (自分のファイル以外への通信の拒否) も効く。
- 線を文字の下に通すかどうかは、DEV-083 の V2 (描く順) と V4 (守る文字に触れない) で検める。

**N2. 表示語を折らない (`white-space: nowrap`、`word-break: keep-all`)**

- 店名・見出し・巨大な表示語にだけ許す (役割は content、事実の値の段落には付けない)。
- はみ出しは、今の `TEXT_BOX_OVERFLOW` と横のはみ出しの掃引で落とす。
- 語の途中の改行を測る検査を足す (`fidelity-measure.ts` の words_broken と同じ考え方)。
- 段 B に入れたい。

**N3. 256px を超える表示語 (上限 640px)**

- `decoration` の巨大な文字 (縁取りの 待つ・ぬるい など) にだけ許す。文字を持つ `decoration` は V1 で止まる。
- だから、表示語は `content` 要素で、文字は固定のラベルか店名の飾りに限る (DEV-083 3.1(c) の「縦書き、装飾」と同じ扱い)。
- 段 B の `type_scale` に含める。

## 3. 安全をどう保つか (オーナーの3つの問い)

**(1) 特定の表示要素だけに許せるか**

- 許せる。すべての緩めは、役割 (`data-comp-role`) と能力の旗 (V7、spec の `capabilities`) に結び付ける。
  - 例: position・回転・`decoration_svg` は `decoration` と板 (`media`) だけ。縦書きは店名・見出し・説明だけ。
- 役割は宣言を信じず、DOM の中身から検める (段 A で作られている)。
- 守る文字 (事実と免責) には、重ねも回転も縁取りも許さない (DEV-083 I2・V4)。

**(2) 外の URL、画像の参照、JS、CSS を経た外への通信をどう拒むか**

次のものは変えない。

- 字句の段で `url(` を、`assets.json` に載った資産の道 (ハッシュで照らす) にだけ許す (`CSS_URL_NOT_ASSET`)。
- `@import`・`image-set()`・`-webkit-image-set()`・`src()` は拒否のまま。
- HTML の `<script>`・イベント属性・`javascript:`・`data:`・外の URL・インラインの `<style>` の拒否 (`htmlSourceProblems`) は、そのまま残す。インラインの SVG も許さない (N1 は `<img>` の資産だけ)。
- 描画は JS を無効にし、自分のファイル以外への通信を拒む。拒否した数は報告に残る。
- SVG の資産は構文検査とハッシュで照らす。中の `href`・`url(`・`<image>`・`<use>` は拒否する。

足す検査 (落ちるべき例):

- SVG の中の外部参照 (`<image href>`、`<use href="http://…">`、`style` 属性の中の `url()`、`<a>`)
- CSS の新しい性質での `url()` の持ち込み (グラデーションの値の中の `url`、`-webkit-mask`)
- 縁取りや回転を事実に付ける

**(3) 既存の worker の生成の道が変わらないか**

- 変わらない。緩めはすべて、明示した能力の旗 (`PageCssOptions` に足す) があるときだけ効く。
  - 今の `verticalName` の旗と同じ作りである。
  - 旗の既定は空で、今の生成の道 (`scripts/sales-design-worker/` と `comp-impl/run.ts`) は旗を渡さない。
- テストで固定すること:
  - 旗無しの `cssProblems` の結果は、今の許可一覧の全プローブで不変である (既存のテストに足す)。
  - 既存の合成の器 (`synthetic-wagashi`) と、今通るすべてのページが、そのまま通る。
