# Phase 2f のスマホ品質検査 (DEV-134、report-only)

`lib/design-agent/phase2f/mobile-quality.ts`。Phase 2f の B方式・C方式の試作を描画するとき、SP 390 の同じページ
(JS 無効・通信遮断、画像を撮ったあと) で、読めるか・押せるかを検める。**止めない。**結果は artifact の
`observed.checks.mobile` に記録され、intake は所見を警告 (`mobile_findings:...`) として出すだけで、状態を変えない。

## 何を見るか

| コード | 意味 | 由来 |
| --- | --- | --- |
| `SP_TEXT_TOO_SMALL` | 12px 未満の文字 | shop-CSS の文字検査 (`MIN_FONT_PX`) |
| `SP_TEXT_CLIPPED` | 祖先の箱に切られた文字 | 同 (`MEASURE_SCRIPT`) |
| `SP_TEXT_OFFSCREEN` | 画面の横へはみ出した文字 (はみ出しを隠したページでも) | 同 |
| `SP_TEXT_COVERED` | 別の要素 (飾りの線・図形を含む) に覆われた文字 | 同 |
| `SP_TEXT_OUT_OF_BOX` | 自分の箱からはみ出した文字 | 同。試作向けに測り直す (下) |
| `SP_TEXT_OVERLAP` | 文字の上に文字 | 同 (`overprinted`) |
| `SP_TEXT_FADED` / `SP_TEXT_SQUEEZED` | 薄すぎる (不透明度 0.85 未満) / 細く押し込まれた | 同 |
| `SP_FACT_HIDDEN` | 事実が SP でどこにも見えない | 同。ほかの所で見えていれば所見にしない |
| `SP_TAP_TARGET_TOO_SMALL` / `SP_TAP_TARGET_BELOW_44` | 押す所が 24px 未満 / 44px 未満 | 新規 (WCAG 2.5.8 / 2.5.5)。文中のリンクは除く |
| `SP_SHOP_NAME_NOT_IN_FIRST_SCREEN` | 390×844 の1画面目に店名が無い | 新規。二つに分けて組んだ店名も数える |
| `SP_CHECK_FAILED` / `SP_CHECK_SCOPE_CONFLICT` | 検査できなかった (合格扱いにしない) | — |

閾値は既存の検査のものをそのまま使い、新しく決めていない (44px と 24px は WCAG の値)。

## 信頼性の確認 (2026-10-31)

DEV-133 の評価で作られた実際の試作12枚 (架空店舗3つ × スキルあり/なし × 2案) に掛け、所見を1つずつ
実測と画面で確かめた。

| 段階 | 所見 | 誤検知 | 内訳 |
| --- | --- | --- | --- |
| 最初の版 | 14 | 9 | 文字を直に置いた flex/grid を一律「箱の外」とする shop-CSS の約束と字間の末尾 (4枚)、二か所に出す店名の一方を隠した (2枚)、意図して画面外へ置いたスキップリンク (2枚)、二つに分けて組んだ店名 (1枚) |
| 直した版 | 5 | 0 | 押す所が 44px 未満 (4枚: 29×44、26×24、39×37 など実測で確認)、不透明度 0.75 の文字 (1枚) |

直したこと: 箱の外の判定を、その文字を持つ要素の箱に対して字間ぶんを許して測り直す。画面の横に丸ごと
外れたラベルとリンクは意図した隠し方として数えない (事実は数える)。隠れた事実は、ほかで見えていれば数えない。
店名は1画面目の文字を順につないで探す。どれもテスト (`tests/unit/design-agent/phase2f/mobile-quality.test.ts`)
に固定した。合成ページで、それぞれの所見が出ることも確かめている。

## 限界

- 12枚の小さな確認である。縦組みや大きく重ねた試作での誤検知は、まだ十分に見ていない
- 文字の色と地のコントラストは見ていない (shop-CSS の画素の検査は、試作の自由な CSS には持ち込んでいない)
- SP は 390px の通常の viewport で描く (モバイルの emulation ではない。Phase 2f の描画と同じ)
- report-only である。自動修正や停止に使うのは、もっと多くの試作で信頼性を確かめてからにする
