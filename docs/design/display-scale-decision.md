## 1. 先に結論

- **256px の安全上限は保たれている。** 旗が下りていると、計算後の `font-size` が 256px を超える文字は、店名でも事実でも飾りの語でも、すべて `TYPE_ABOVE_ROLE_CAP` で落ちる。`rem` と根の大きさの掛け合わせ・`em`・`%`・`h1` の既定の 2em・継いだ値・`vw`・`clamp()`・`calc()` (生の HTML) も同じ。
- **旗を立てても、256px を超えてよいのは表示語だけ。** 表示語 = 店名の全体と固定のラベル (`COMP_UI_LABELS`) に文字が完全に一致し、子の要素を持たず、`dt`・`dd`・免責の中でない要素。事実・免責・事実の文・略称・飾りの語・混ぜた文・aria-label の細工・継いだ大きさは、すべて落ちる。
- **上限は正確である。** 256px と 640px (40rem) は通り、256.03px・640.03px は落ちる (判定は `px > 上限 + 0.01`)。
- **入りきらない表示語は落ちる。** 1px の掃引が、入りきらない幅だけで `DISPLAY_WORD_BROKEN`・`DISPLAY_OUT_OF_BOX`・`DISPLAY_OFFSCREEN` を出す (端は ±1px)。文字の上の文字 (`TEXT_OVERLAP`)、切り落とし (`TEXT_CLIPPED`)、守る文字のコントラスト (`FACT_LOW_CONTRAST`) も、大きな文字で今どおり効く。
- **ただし、3店の目に見える損失は戻らない。** C′ が 256px を超えて描く語 (熱い 470px、待つ 500px、まわる 300px ほか) は、**1つも表示語ではない** (飾りの語)。今の対象のまま ON にしても、どれも `TYPE_ABOVE_ROLE_CAP` で落ちる。
- **対象の中の店名の全体は、1440 では 256px に届かない。** 店名の全体が箱に入る最大の大きさは、つぐ手 76px・輪 194px・ゆげ湯 156px (1440)。1920 でも 110 / 262 / 276px。display_scale が要るのは、1920 前後の輪とゆげ湯の店名だけである。
- **ON にしても、今の3店の描画は1画素も変わらない** (3店の strict は 256px を超える文字を持たない。§4 の SHA)。

### 3.1 旗が下りているとき (今の本番)

**静的な文法** (`page-css.ts`、テストで固定):

- **文法は役割を知らない。** 旗を立てると、`.address-fact`・`dd`・`body`・`html`・`*` の 640px も通る。`html { font-size: 40rem }` と `.x { font-size: 40rem }` も通る (ページの中では 25,600px)。役割と掛け合わせを止めるのは、描画の `TYPE_ABOVE_ROLE_CAP` だけである。

### 3.4 幅の検査 (落ちるべきときに落ち、そうでなければ通る)

左右 16px の余白の箱に、表示語の `h1` を1つ置いた。必要な幅 = 1920 で測った語 (空白の間) の幅 + 32px。

| 表示語 (大きさ) | 必要な幅 | 1px の掃引で落ちる幅 | 確かめる幅 |
|---|---|---|---|
| 店舗情報 (300px) | 1232px | 320–1231 (`DISPLAY_WORD_BROKEN`、320–331 は `DISPLAY_OUT_OF_BOX` も) | 1024 以下で落ち、1280 以上で通る |
| 店舗情報 (300px、nowrap と併用) | 1232px | 320–1230 (`DISPLAY_OUT_OF_BOX`・`DISPLAY_OFFSCREEN`。折れは出ない) | 1024 以下で `TEXT_BOX_OVERFLOW`・`OVERFLOW_HORIZONTAL` ほか |
| 電話 (640px、上限ちょうど) | 1312px | 320–1311 (`DISPLAY_WORD_BROKEN`。1字が入らない 671 以下は `DISPLAY_OUT_OF_BOX` も) | 1280 以下で落ち、1440 で通る |
| 架空銭湯 ゆげ湯 (400px、空白で折れてよい) | 1632px (長い方の語) | 320–1631 | 1440 以下で落ちる |
| 架空銭湯 ゆげ湯 (400px、nowrap) | 3032px (1行) | 320–1920 の全部 | 全部で落ちる |

- **日本語は字の間でも折れる。** 空白で2行に分けたい店名でも、行の詰め方しだいで語の途中で折れる幅が出る。架空銭湯 ゆげ湯 を 200px にすると、2語がそれぞれ入る 832px 以上でも、1132〜1531px で「架空銭湯 ゆ / げ湯」と折れて `DISPLAY_WORD_BROKEN` になる。`word-break: keep-all` (display_nowrap) を併せると、落ちるのは 320〜830 だけになる。**2行の大きな店名には display_nowrap の keep-all が実質的に要る。**
- **文字の上の文字:** 2列の格子 (`minmax(0, 1fr)`) で 600px の1字が隣の列の住所に重なると、1024px で `TEXT_OVERLAP`・`TEXT_BOX_OVERFLOW`、掃引で `DISPLAY_OUT_OF_BOX`。1920px では何も出ない。
- **切り落とし:** 親に `overflow: hidden` と高さがあると、確かめる幅で `TEXT_CLIPPED` が出る (ページは動かない)。`overflow` は文法が拒む (`CSS_PROPERTY`)。
- **高さの固定 (文法が通す):** 語の箱そのものに高さがあれば、掃引は1行に入らない幅 (320–1531) で `DISPLAY_OUT_OF_BOX` を出す。**親の箱に高さがあるときは、掃引は何も出さない** (語の箱が行に合わせて伸びるため)。1440 では、はみ出した行が下の住所に重なり `TEXT_OVERLAP` で落ちる。間の幅は、32px の掃引 (守る文字だけ) と確かめる幅に頼る (§6・§7)。
- **コントラストと墨:** 400px の店名を守る文字 (required) にすると、`#dddddd` で `FACT_LOW_CONTRAST`、`#1f1d1b` では `FACT_*` が出ない (大きな字形でも墨の検査は通る)。
- **SP:** `@media (max-width: 600px)` だけの 260px の電話は、確かめる幅と 32px の掃引のうち 600px 以下の全部で落ち、601 からは落ちない。

## 6. 証明していないこと

- **1920px より広い幅、320px より狭い幅、整数でない幅。** 掃引は 320〜1920 の整数の幅だけ。輪とゆげ湯の店名が 256px を超えて入るのは 1920 前後からで、その先の幅 (大きな画面) は測っていない。
- **ブラウザの拡大率 (zoom)・文字の大きさの設定・最小の文字の大きさの設定・端末の画素比。** 検査は 100% の拡大でだけ走る。利用者が文字を大きくすると、640px の語は確かめた幅より狭い幅で入らなくなる。
- **電話の文字の自動拡大 (text autosizing)。** viewport の meta があるページでは起きない。meta の無いページの電話の擬装では、計算値と描く大きさがずれうる。調べていない。
- **Chromium 1194 以外の描画系** (WebKit・Firefox)。字の詰め方と折れる位置は描画系で違う。日本語の行の詰め方 (§3.4) は特に差が出る。
- **ほかの書体。** 手元の容器の書体でしか走らせていない (`web_font` は未実装)。
- **zoom・transform・`scale`・`::first-letter` で大きく描くこと。** これらは計算後の `font-size` を変えないので、描画の上限は**見えない** (テストで「通る」ことを記録として固定した)。守りは静的な文法 (`CSS_PROPERTY`、疑似要素の拒否) と HTML の許可一覧 (`style` 属性・`svg`・`math` の拒否) の1枚である。
- **親の箱の高さを越えてはみ出す表示語の、確かめる幅の間。** 1px の掃引は語の箱だけを見る。重なる相手が守る文字なら 32px の掃引が見るが、32px より細い帯は見ない。
- **900 以外の窓の高さ**、**3店以外のページ**。

## 7. 危険

- **静的な文法は役割を知らない:** 旗を立てると、どの選択子の 640px も、`html` の 40rem も文法を通る。描画の `TYPE_ABOVE_ROLE_CAP` が唯一の守りである。run.ts は確かめる幅と 32px の掃引の全部で `phaseBScan` を呼ぶので、守りが走らない道は無いが、守りは1枚である。
- **大きな語は長いページを作る:** 折れた 300px の店名は、つぐ手のページを 3,000px 伸ばした。折れは `DISPLAY_WORD_BROKEN` で落ちるが、空白で正しく折れた大きな店名 (keep-all) は、縦に長くなっても落ちない。見た目の判断になる。
- **列が押し広げられる:** 大きな1字は格子の `auto`・`1fr` の列を広げ、隣の語を折る (ゆげ湯の scale_wide で ゆげ/湯)。略称は表示語でないので、その折れは今の検査では落ちない (DEV-170 §7 と同じ)。
- **親の高さ:** 語の箱でなく親の箱の高さを越えるはみ出しは、1px の掃引では見えない (§3.4)。
- **1px 未満の超過:** 640.01px は通る (判定の余地)。描く大きさの差は 0.01px で、危なくはない。

## 8. ON にしたら変わること

- spec が `display_scale` を宣言でき、そのページだけ `font-size` の px 12〜640・rem 0.75〜40 が文法を通る。spec の `type_scale.display_px` も 640 まで。
- そのページだけ、表示語の上限が 640px になる。表示語でない文字は 256px のまま。
- そのページだけ、`DISPLAY_WORD_BROKEN` を見るようになり、1px の掃引 (320〜1920) が表示語に掛かる (1ページ約 1 秒増える。`phase-b-design.md` §8.6)。**宣言したページでは、店名の全体やラベルが語の途中で折れると落ちる** (今は落ちない)。つぐ手の strict B は、宣言すると 601〜785px でも落ちる (その幅は今も別のコードで落ちている)。
- 宣言しないページは何も変わらない。
- 3店の今の見た目は変わらない (§4 の SHA)。C′ の大きな語は、ON にしても対象の外で落ちる。
