## 0. 先に結論

- **3店とも、店の比喩はページ全体の構造になっている。これは C′ (研究の道) の話である。**
  - つぐ手: 金の線が器の割れ目から破片を縫って結び目へ降りる。
  - 輪: ハブから伸びたスポークが修理の駅を吊る。
  - ゆげ湯: 温度計が 熱い→ぬるい→冷たい→沸く→夜 を下る。

  入れ替えテスト (店名と事実を同業の別の店に替える) では、3店とも Hero と流れの両方が成り立たなくなる。B (規則の中の実装) では、3店とも比喩が飾りに縮み、構造は帯の積み重ねか格子に近づく。
- **カンプ (A) から B で失うのは、形・またぎ・大きさである。3店で同じ傾向だった。** 位置の数 (motif の縦の被覆) は B でもあまり減らない。輪だけがはっきり減る (PC 0.58 → 0.31)。
  失うのは、次のものである。
  - 線の形 (曲線・放射)
  - 区画の境をまたぐ重ね
  - 256px を超える飾りの語
  - 縦書き
  - 傾き

  B はタブレットの幅で横にはみ出し (361・632・522px)、巨大な語が折れる。
- **A から C′ で失うものは、構成上 0 である。** 最新の C′ は最新のカンプと同じソースから描くので、描画は同じバイトになる (§4)。意味のある「A→C」の差は、最初の C (`d1`・`d1-v2`) との差である。
  最初の C は核をほぼ保ち、カンプに無かったタブレットの組みを自分で作った。
- **研究の道 C′ と本番の道 B の差は、能力 (段 B・C・D・N1) を全部 ON にしても大半が残る** (§5)。
  - はっきり戻るもの:
    - ゆげ湯の火の帯と温度計の色の流れ (段 B `gradient_ground`)
    - 区画の境にかかる計器・板・管 (段 C `layered_decoration`)
    - 語の縦書き・小さな傾き・縁取り (段 D、事実の文には効かない)
  - 戻らないもの:
    - 曲線
    - 放射のスポーク
    - 256px を超える飾りの語
    - 縦の事実の文
    - 札ごと傾けた板
    - 板の影

    これらはオーナーの判断か、N1 の資産ごとの目視が要る。
- **CTA:** 予約の事実は3店とも事実パックに無い (情報不足。作らない)。
  - 連絡と時間と所在地は、どの版でもページの最後の区画 (ページの高さの 86〜98%) にだけある。1画面目には無い。
  - いちばん強いのは ゆげ湯 C′ の朱の電話の札である。
  - 1画面目に電話か時間を出すかは、構成の判断としてオーナーに残す。
- **素材:** 写真は3店とも仮の板である。C′ は、描いた釉・木目・湯の波紋・タイルで板の役割と比率を示す。素材の質 (焼き物・金属・湯の質感) は、実写真が入るまで評価できない。
- **この DEV で直したもの:** Issue #193 の HOLD の 5・6・7・8 と、輪の板の影 (HOLD 2)。新しい版はカンプ3つと C 3つで、古い版は残した (§6)。
  - HOLD 1 (輪 の字の箱の角) と 3 (つぐ手 SP の横の名前) は、オーナーの判断として変えていない。
  - HOLD 4 (3つの構図の弱さ) は、安くは直せないので残した。

## 2. 評価の物差し

各項目を 0〜3 で付ける。**数は Claude の目と下の測りの組み合わせで、オーナーの判定ではない。** 1つのセルには 1440 / 768 / 390 の順に3つの数を書く。

| 項目 | 3 | 2 | 1 | 0 |
|---|---|---|---|---|
| **独創性** (その店の比喩か、テンプレートでないか) | 比喩がページ全体の構造になり、入れ替えテストで Hero と流れの両方が成り立たなくなる | 比喩は Hero と一部の区画だけ。または幅の都合で構図が崩れる | 比喩が飾りに縮み、骨格は帯の積み重ねか格子 (SKILL の汎用の印のどれか) | テンプレートと見分けられない |
| **モチーフの忠実性** (A₀ の核の形・またぎ・大きさが残るか) | 形もまたぎも残る | 形を単純にして残る | 位置だけ残り、形が変わる | 失われる |
| **可読性** | 1px の全幅の掃引で、飾り・板・影が文字に届かない、文字が切れない、4.5:1 以上 (大きな字は 3:1)、語の途中で折れない | 局所の当たりが少し、または掃引していない | 語の途中の折れか、覆われた説明の行がある | 横のはみ出しか、読めない所がある |
| **CTA** (電話・時間・所在地、予約) | 情報が揃い、電話が目立ち、ページの途中にも入口がある | 情報が揃い、電話が大きいが、最後の区画にだけある | 情報はあるが、その幅で覆われるか、はみ出す | 欠ける |
| **素材** | 実写真か、承認された資産 | 仮の板だが、役割・比・描いた質感で写真の場所が分かる | 仮の板 (単色・同じ大きさ) | 何も無い |

**測り (どれも品質の判定ではない):**

- `fidelity-measure` の位置の数 (`poc/*/fidelity-report.json`): 核の縦の被覆・境をまたぐ数・覆われた説明の行・折れた巨大な語・はみ出し。
- CTA の位置: ページの高さに対する割合、字の大きさ、1画面目に入るか。リポジトリの外の使い捨ての道具 `dev176/cta.mjs` で測った。
- C′ だけ、1px の全幅の掃引を 3つの書体で行った (§6)。A₀・B・C は掃引していない。

- **A₀・C (1440):**
  - 縦の つぐ手 (250px) の横で、割れた器を金の線が通る。
  - 線は破片の板を縫って、断面・乾く時間・相談を通り、結び目まで蛇行する。

  - 線画の器が、漆の内側と釉の調子の器になった。

  - 来店で線が器の割れ目に入って終わる。

  - つぐ/手 が2行に折れる。
  - 器は平たい半円である。
  - 線は中央の1本の直線で、どの区画も同じ3列の格子である。
  - 板は同じ色の長方形で、左右に交互に置かれる。これは失敗パターン「左文字・右写真の繰り返し」に近い。

  - C′ (この DEV の版) では、線が結び目から直った器の割れ目まで続く (HOLD 8)。
- **390:**
  - A₀・C は縦の名前が器の上に立つ。
  - C′ は名前が器の上の紙の地に横に置かれる (HOLD 3、カンプと違う。忠実性 2)。
  - C′ の線は中央をまっすぐ下る。文字は地の帯に乗って線の上に出る。
- **CTA:** 情報は来店の区画にだけある (ページの 86〜97%)。電話は 40〜44px、時間は 20px (B の 390 は 17px)。B の 768 は横のはみ出しで情報が画面の外へ出うる (1)。

## 4. 工程が失うもの: A→B と A→C

| 段 | 失うもの | 原因 | 3店の例 |
|---|---|---|---|
| A₀ → B | 線・車輪・帯の**形** | 装飾の SVG・曲線が許可の外 | つぐ手の曲線、輪の放射、ゆげ湯の滑らかな帯 |
| A₀ → B | 区画の境の**またぎ**と重ね | 位置・`z-index`・負の margin・`transform` が許可の外 | 3店の巨大な語、輪の計器、ゆげ湯の湯船 |
| A₀ → B | 飾りの語の**大きさ** | `TYPE_ABOVE_ROLE_CAP` (256px) | 待つ 500px、まわる 300px、熱い 470px |
| A₀ → B | **縦書き**・**縁取り**・**傾き** | `writing-mode`・`-webkit-text-stroke`・`transform` | 縦の事実の文、縁取りの語、傾いた板 |
| A₀ → B | **タブレット** | カンプにタブレットの設計が無く、B は PC を縮めた | 3店とも 768 で横にはみ出し、巨大な語が折れる |
| A₀ → C | ほぼ無い | C は B方式の隔離された道で、許可一覧の外の表現を使える | C はタブレットの組みを自分で作った |
| A → C′ | 無い (構成上) | C′ は最新のカンプと同じソース。描画は同じバイト | — |
| C′ → 本番 | C′ の表現のほぼ全部 | 能力はすべて OFF。ON にしても §5 のとおり大半が残る | — |

**正直に言うこと:** 「A から C で何も失わない」は、C が許可一覧の外の表現を使ってよい研究の道だから成り立つ。本番の道で同じページを出す方法は、まだ無い。
`fidelity-measure` の位置の数は形を測らない。だから B が C と同じ数 (ゆげ湯 1.00) になることがある。また、つぐ手の「境をまたぐ数」は、どの版も 0/5 と出る (線の要素が区画ごとに分かれていて、区画の境を1つの要素がまたがない)。

## 5. 段 B・C・D と N1 (すべて OFF) で閉じる差、閉じない差

「戻る」は、その能力の判断シートが 3店の strict B に足して確かめた範囲で言う。どの能力も ON にするのはオーナーの別の承認である。

- 3店の C′ が B に勝つ所のうち、能力で閉じうるのは「色の流れ・またぎの構図・語の縦と傾きと縁取り」までである。

- 「縦の事実の文・札ごとの傾き・巨大な飾りの語・板の影・写真」は、どの段でも閉じない。オーナーの判断か実写真が要る。

## 7. オーナーに決めてほしいこと

1. **成功例の水準と認めるか。** 写真が仮の板のままでは、Claude は認めない。オーナーが画像を見て決める。
2. **HOLD 1 (輪 の字の箱の角)。** 字の墨はスポークに掛からない (DEV-177 で 0)。四角い字の箱の角だけが丸いハブの外に出る。消すにはハブを約 35% 大きくするか、字を小さくする必要がある。
3. **HOLD 3 (つぐ手 SP の名前の向き)。** カンプは縦、C′ は横。縦に戻すなら、名前が器の暗い内側に掛からない別の置き方が要る。

5. **創作の文**: 区画のラベル、待つ、のれんの ゆ と色。
6. **CTA の位置**: 電話・時間を1画面目かページの途中にも出すか (今はゆげ湯の時間だけが途中にある)。予約は事実が無いので出さない。
7. **能力の ON** (別の PR と承認): 得がはっきりしているのは `gradient_ground` (ゆげ湯の火の帯) と `layered_decoration` (計器・湯船の板のまたぎ)。
8. **実写真**: 3店とも、板の役割と比率は決まっている。素材の質は写真が入るまで評価できない。
