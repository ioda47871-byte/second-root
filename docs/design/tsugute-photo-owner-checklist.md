# つぐ手の写真6枚: オーナー向けチェックリスト (DEV-182)

2026-11-05。架空の金継ぎ工房「つぐ手」のデザインの品質を確かめるための写真です。**公開のサイトには使いません。リポジトリにも入れません** (リポジトリは公開なので、SHA-256 と大きさだけを記録します)。

- まだ写真は1枚もありません。Claude は写真を集めたり、作ったり、買ったりしません。
- 依頼文の全文は `docs/design/tsugute-photo-request.md` §3 にあります。このチェックリストは、その要点と、DEV-182 で上げた大きさ (ph-kake) をまとめたものです。
- 写真が届いても、評価は `placeholder_limited` のままです。描いた画像をオーナーが見るまで、成功例の水準とは言いません。

## 1. 送るもの (6枚、ph-dry は2枚に分けてもよい)

| 枠 | 写すもの | 向き | 目標の大きさ (これ以上) | 下限 (例外の記録が要る) |
|---|---|---|---|---|
| ph-ware | ふたつに割れた器の接写 | 横 4:3 | 1610×1208 px | 1210×908 px |
| ph-kake | 縁の欠けた器 | 横 4:3 | **1370×1028 px** | **1030×773 px** |
| ph-hibi | ひびの入った器 | 横長 16:9 | 1600×900 px | 1200×675 px |
| ph-dry (1枚なら) | 乾くのを待つ器 (棚や箱の中) | 正方形 1:1 | 1300×1300 px | 980×980 px |
| ph-dry (2枚なら) | 同じ。PC 用と SP 用 | PC 縦 2:3 / SP 横 4:3 | PC 640×960 px・SP 1300×975 px | PC 480×720 px・SP 980×735 px |
| ph-hand | 筆で金を蒔く手元 | 正方形 1:1 | 1660×1660 px | 1250×1250 px |
| ph-desk | 線を相談する机と器 | 横 4:3 | 1030×773 px | 770×578 px |

- **スマホで撮ったままの大きさ (4032×3024 ほど) なら、どの枠も足ります。** 縮めずに送ってください。
- ph-kake は、依頼文 §3 の 1230×923 から **1370×1028 に上げました** (DEV-182)。最新のデザイン (C の d1-v8) は、タブレットの幅でこの板が大きいためです。古い大きさの写真は、今の道具 (d1-v3) では通りますが、最新のデザインでは2倍を割ります。
- 「下限」は、オーナーが実物を見て「ぼやけない」と決め、その理由を記録した時だけ使います (`scale_exception`)。Claude は例外を決めません。下限より小さい写真は、例外があっても使えません。
- 主役 (割れ目・欠け・ひび・器・手元) を**真ん中に寄せ、周りに余白**を残してください。PC とスマホで切り抜く形が違います。

## 2. 写さないもの

- 人の顔、誰か分かる体の特徴 (指輪・入れ墨・ほくろ・爪の装飾)
- 看板・店名・ロゴ・住所・電話番号・車のナンバー、紙に書いた名前
- 実在の店や家だと分かる場所、他の器のブランドの刻印
- 他のサイトから保存した写真、AI で作った画像、有料の素材

## 3. 形式

- JPEG・PNG・WebP のどれか。拡張子と中身を合わせてください (`.jpg` の名前の PNG は拒まれます)。
- スマホで縦に構えて撮った写真は、そのままで大丈夫です (向きの情報 EXIF を読みます)。ただし、**向きの情報が2つある・壊れている JPEG は拒まれます**。編集アプリで一度書き出すと直ることが多いです。
- 撮影場所 (GPS) などの情報は、切り抜いた写真からは消します。元の写真は非公開の置き場から出しません。
- ファイルの名前は、英字・数字・ハイフン・下線だけで 81 字まで、拡張子は `.png`・`.jpg`・`.jpeg`・`.webp` (例: `tsugute-ph-kake-1.jpg`)。日本語や空白の名前は、置くときに付け直します。

## 4. 権利について教えてほしいこと (1枚ごと)

| 項目 | 例 | 公開に残るか |
|---|---|---|
| 撮った人 / 権利を持つ人 | 本人の名前 | **残らない** (非公開) |
| 素材の種類 | 自分で撮った / 店が渡した / 規約で使える無料素材 | 残る |
| 編集・切り抜き・商用の利用をしてよいか | 3つとも「はい」が要る | 残る (真偽値) |
| 有料の素材でないこと | 有料なら使えません | 残る |
| 使ってよい期限 | 無ければ「無し」とはっきり | 残る |
| 同意の記録がどこにあるか | メールの件名、書類の番号 | **残らない** |
| 受け取った日 | 2026-11-10 | 残る |
| (無料素材なら) 規約のページ | 本文を保存して SHA-256 を記録します | SHA だけ |
| 誰か分かる人・実在の店が写っていないこと | 「写っていない」 | 残る |

- 1つでも欠けると、その写真は使えません (道具が拒みます)。
- 欄の形が壊れていると、道具はまず形の誤りだけを返し、直してから中身 (SHA・大きさ) を照らします。2回のやりとりになることがあります。

## 5. 渡し方

- **GitHub の Issue・PR・コメントには、写真も権利の内容も貼らないでください。**
- 渡し方はまだ決まっていません (`photo-intake.md` §10 の2)。オーナーが決めてください。
- 受け取った写真は、オーナーの手元のリポジトリの `design-library/research/quality-pipeline/.intake/photos/` にだけ置きます (git が無視する場所)。リンク (symlink・hardlink) は拒まれます。

## 6. 受け取った後 (それぞれ承認が要る)

1. 写真と権利の記録を受け取る。
2. 枠ごとに主役の箱と alt を書く。下限を使う枠は、オーナーが例外を記録する。
3. 道具で差し替える (`--out` はリポジトリの外)。PC 1440 と SP 390 で描き、オーナーが見る。
4. **最新のデザイン (d1-v8) に差し替えるには、先に道具の直しが要ります** (`tsugute-photo-request.md` §7)。今の道具が入れられるのは d1-v3 だけです。
5. 公開に使うことは、さらに別の承認です。
